## P10.1 审计（第二层前瞻 + 12% 持仓归因）

### 查出并修复第二层前瞻偏差（极值日 ≠ 可知日）

- **审计方法（最重要的方法论产出）**：Prefix Invariance Test —— 对任意历史日期 t，
  「用全部数据跑出的 t 日状态」必须等于「只用截至 t 的数据跑出的最后一天状态」。
  它**不预设泄漏发生在哪个模块**，swing / confirmation / trend / secondary / line / volume / regime
  任何一层的未来函数都会被同一次比对抓住。新增 `research/lookahead_audit.py` +
  `scripts/audit_lookahead.py`（支持 `--all` / `--n`）。
- **修复前 36 点里 21 点不一致（58%）**。指纹：`2008-09-23 full='DOWN@2008-09-23' prefix='UP@2008-09-22'`
  —— full 里存在一条**极值日正好等于 t** 的浪，prefix 里不存在。
- **根因**：`detect_swings.add()` 记录的 `end_date` 是**极值点当天**，但这条浪要到价格
  从极值反向走够 3% 之后才被创建。而 `available_date = max(本浪结束日, 确认浪结束日)`
  用的全是极值日，完全没体现识别延迟。
- **修复**：`Swing.detected_date`（识别日）+ `Swing.known_date` property；
  `confirm_primary` 全部改用 `known_date`；未确认浪在窗口未关闭时 = `date_max()`（永不可用）；
  匹配加约束「确认浪必须在窗口关闭前被识别」并取 earliest-known；
  provisional 浪彻底踢出确认判定（旧代码 `if s.end_date is not None` 是 no-op）。
- **修复后 5 配对 × 61 点 = 305 点全部一致**。固化为核心回归测试
  `tests/run_tests.py::test_engine_prefix_invariance`（测试总数 13 → 15）。

### 顺手修掉 O(n²) 性能问题

- `detect_line_pair` 在逐日主循环里每行都重建 `df["high"].tolist()`，21 年数据 26 秒。
  改为预提取列表 + 新增 `combine_line`；`up_down_volume` 加等语义数组版 `up_down_volume_arr`。
  **26.1s → 1.17s（22 倍）**。
- 用 `scripts/verify_refactor.py` 以 P10 冻结 CSV 为基准**逐字段**证明输出完全没变
  （不是"看起来一样"，是逐列比对）。Prefix 审计能跑起来靠的就是这一步。

  胜率 50.6%；TREND_DOWN 的 MFE/MAE 0.76 < 1）。只剩 13.3% 是实现闸门。
- **没有任何单道闸门是瓶颈**：撤掉任何一道，暴露最多 11.73% → 13.09%。

  +11.56%（上证+深证）；T3 从 +2.40% 变成 −6.87%。**不得把任何子状态改成 RISK_ON。**

### 新增个股数据层 `data/stock_loader.py`（重要踩坑记录）

- **mootdx 现在完全不可用**：三个参数组合全返回 0 行（~6s 超时）。不要再试。
- 网易 `quotes.money.163.com` 502；腾讯 `ifzq.gtimg.cn` 不带区间只给 320 根，不够长回测。
- **东财 push2his 个股可用（0.9s，6012 根回溯 2001）但会断连**：连续请求几十次后
  `RemoteDisconnected`，本机易被限流 → 只作兜底。
- **最终主源：新浪 `CN_MarketData.getKLineData` + `datalen=6000`**。关键认知：
  datalen 上限不是 1023（那只是默认值），给多少返多少，实测可回溯 2001-08。
  6 线程并发抓 280 只约 5 分钟，0 失败。
- **个股符号映射与指数不同**（静默错误的坑）：个股 `000001` = 平安银行 = 深市 `sz000001`；
  指数 `000001` = 上证指数 = 沪市。`data/loader.py` 的 `_sina_symbol` 是按指数写的，
  直接拿来抓个股会把 000001 抓成上证指数。
- 新浪只给成交量，`amount = volume × close` 近似，仅用于流动性门槛。

### P11-A/B 结论（`out/p11_stability*.md`，新增 `research/stability.py`）

- **信息含量高度集中在 2005-2010**（pair0，fwd60）：
  ON−WAIT 从 **+9.6pp** → 2016-2020 **−1.7pp** → 2021-2026 +4.1pp；
  **OFF−WAIT 从 −21.3pp 一路衰减到 −0.9pp**（避风价值基本消失）。
  全样本 ON 比 WAIT 高 5.7pp 很好看，拆分区间后现出原形。
- **逐年口径的坑**：RISK_ON / RISK_OFF 是**按年交替**的状态，同一年内极少共存，
  所以"同年价差"22 年里只有 2 年算得出来。正确基准是**同年 WAIT**（每年都有）。
- 结果：pair0 的 RISK_ON 优于同年 WAIT 只有 **2/9 年**；2007 年 RISK_ON fwd60 +17.0%
  而同年 WAIT **+22.9%** → **确认让人在牛市里晚进场**（道氏确认滞后的真实代价）。
- **配对选择本身不稳定**：pair0 UP>DOWN 4/4、滚动价差正 92.4%；
  pair1（上证+深证）UP>DOWN 仅 **1/4**、滚动正 **54.2%**。

### P11-C 结论（`out/p11_overlay*.md`，新增 `research/overlay_regime.py`）

- Alpha = 最简横截面动量（120 日、前 30、20 日调仓、T+1、单边 12bp），**故意不含 PA**。
- **两条必须一起看的结论**：
  1. **Dow 择时不是"仓位变低"的假象** —— 对照组是**同平均暴露的常数缩放**，
     其 Sharpe 恒等于满仓 Alpha（常数缩放不改变 Sharpe）。Dow 在 6 组映射里
     **5 组**把 Sharpe 从 0.379 抬到 0.400~0.589。
  2. **但打不过 MA200** —— MA200 参照 Sharpe 增益 0.208，Dow 只有 **1/6** 组超过它
     （pair1 是 **0/6**）；最好的 Dow 映射（M2）Sharpe 增益 0.210，**刚好追平**。
- 分区间不稳：M1 在 2005-2010 CAGR 6.39% → 17.50%、2021-2026 3.43% → 7.47%，
  但 **2011-2015 是 −3.98% vs 对照组 +0.47%**。
- **"最简单动量"在 A 股跑输等权**：7.19% vs 16.98%（Sharpe 0.379 vs 0.721）。
  横截面动量在 A 股本就偏弱，不是实现 bug。→ 真正决定收益的是 Alpha 层。

### P11 踩到并堵住的两个口径陷阱（已写进 README 第 8 节 + 技能）

1. **两腿时间窗必须相同**：个股数据比指数长（可到 1991 年），不裁剪就变成
   "Alpha 跑 1991-2026、Dow 跑 2005-2026"的错位比较。
2. **`close = 0` 不是价格**：新浪用 0 标记停牌，不处理会产生 **单日 −1650%**
   的收益，再顺着权重漂移 `w*(1+r)/denom` 把权益曲线打穿。
