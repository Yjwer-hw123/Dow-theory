## 5. 数据源教训（踩过的坑）

- 指数：新浪 `money.finance.sina.com.cn`（主）→ 腾讯 → 东财（本机易断连）。
- 个股：mootdx 完全不可用（返 0 行）；网易 502；东财 `push2his` 连续几十次后 `RemoteDisconnected`（只作兜底）。
  主源 = 新浪 `CN_MarketData.getKLineData` + `datalen=6000`（上限不是 1023；实测回溯 2001-08）。
- **个股与指数的符号映射不同**（静默错误）：个股 `000001` = 平安银行（深 `sz`）；指数 `000001` = 上证指数（沪）。不要复用同一个映射函数。
- `close == 0` 不是价格：新浪用 0 标记停牌，不处理会产生单日 −1650% 假收益，再经权重漂移打穿权益曲线。
- 两腿时间窗必须相同：个股数据可回溯 1991 年，必须裁剪到与指数一致。
