## 1. 研究问题与最终目标

**母问题**：在已经处于上涨结构的股票中，哪一个进入时点的未来收益分布与下行风险更有利？

| 编号 | 子问题 | 对应阶段 |
|---|---|---|
| E1 | 趋势识别后的第一次确认回撤，之后是否更容易恢复原结构？ | A |
| E2 | 震荡上行中的缩量调整，是否存在可重复的承接特征？ | B |
| E3 | 趋势成熟后的高位震荡，结构是否已经衰减、继续进入的风险是否更大？ | C |

**最终交易目标（阶段 2 只验证前两项与第三项的扣成本前版本）**：

| 目标 | 门槛 |
|---|---|
| 胜率（全部交易，含 flat） | **≥ 50%** |
| 平均盈亏比 | **≥ 2.0** |
| 扣成本前期望值 | **> 0** |
| 跨年度表现 | 合格完整年度中 ≥70% 方向为正 |
| 真实成交 | 阶段 3 验证，不能把研究性固定持有收益当作实际交易成绩 |

若令平均亏损为 1R，50% 胜率、2:1 盈亏比对应：

```
EV = 0.50 × 2R - 0.50 × 1R = 0.50R
```

这是目标，不是已知结论。

## 4. 候选进入周与入场规则

### 4.1 候选集合

对每个 episode，从信号周之后逐周检查：

1. 该周是完整周；
2. 该周收盘 ≥ 最近一个**已确认**周线波段低点（结构仍完好）；
3. 该周不是 episode 终止周。

满足三条的周记为候选进入周 `w`。

**无未来函数**：条件 2 只用 `w` 及以前确认的波段低点（确认索引 = 极值 +2）；终止周是第一个不满足条件 2 的周，当时不可知；特征只用 `w` 及以前的周 K。

### 4.2 入场执行规则

| 项 | 规则 |
|---|---|
| 入场时点 | 候选周最后一个交易日后的**下一交易日开盘** |
| 停牌 | 下一交易日无 bar → 顺延到第一个有 bar 的交易日，最多 10 个市场交易日 |
| 超过有效期 | 10 个市场交易日内仍无 bar → `untradable`，排除并计数 |
| 入场价 | 该有效 bar 的开盘价 |
| 涨跌停 | 阶段 2 不模拟成交；记录入场日是否开盘涨停/跌停，阶段 3 处理 |
| T+1 | 入场当日不能卖出；首次触及计时从入场日的**下一交易日**开始 |
| 持有期 | 入场 bar 记为**第 1 个有效交易日**，详见第 7 节 |

### 4.3 每个 episode 只取一次（主口径）

同一 episode 内，同一类别只取第一次满足条件的候选周。全量候选周作为次要口径，并按 episode 聚类。

## 5. 连续特征

在候选周 `w` 收盘时点计算，全部只用 `w` 及以前的数据。

| 特征 | 定义 | 参数情况 |
|---|---|---|
| `age_w` | 自信号周起的完整周数（信号周 = 0） | 无参数 |
| `run_high` | 信号周至 `w` 的周线最高价 | 无参数 |
| `run_high_week` | **截至 `w`，最近一次达到 `run_high` 的周**；并列时取最晚一周 | 本版明确，无参数 |
| `depth` | `1 - wclose / run_high` | 无参数 |
| `retrace` | `(run_high - wclose) / (run_high - 最近确认波段低点)`，分母 ≤0 记缺失 | 无参数 |
| `vol_ratio` | `run_high_week` 至 `w`（含两端）的周均成交额 / `run_high_week` 之前 12 个完整周的周均成交额；前 12 周不足记缺失 | 12 周沿用既有口径，未验证 |
| `er26` | 26 周 Kaufman 效率比 | 26 周未验证 |
| `mdd_since_high` | `1 - min(low since run_high_week) / run_high` | 无参数 |
| `weeks_since_high` | `w` 与 `run_high_week` 的周索引差 | 无参数 |
| `n_prior_pullbacks` | 信号周之后已确认的周线波段低点个数 | 无参数 |
| `structure_ok` | `wclose ≥ 最近确认波段低点` | 无参数 |

**`run_high_week` 的并列规则**：若第 10 周与第 15 周最高价相同且为当前最高，取第 15 周。这样缩量窗口从最近一次触及最高价之后开始，不会把更早的高点误当作调整起点。

## 6. 三类阶段的映射

### 6.1 A：趋势识别后的第一次确认回撤

- 信号周之后**第一个被 2 左 2 右规则确认的周线波段低点**；
- 候选进入周 = 该低点的**确认周**（极值索引 +2），不是低点当周；
- 每个 episode 至多一个 A 观测；
- 命名理由：上游显示信号时前 26 周涨幅中位 +23.44%，不能称为“趋势启动”；统一称“趋势识别后的第一次确认回撤”。

### 6.2 B：缩量调整

- 候选周满足：`n_prior_pullbacks ≥ 1`、`depth > 0`、`vol_ratio < 1`；
- 不设“缩量多少”的硬阈值；`vol_ratio` 作为连续特征进入分位统计；
- 每个 episode 取第一次满足条件的周。

### 6.3 C：成熟高位震荡（扩展历史分位，PIT）

三条组合：

1. `age_w` 处于截至该决策周之前的历史候选样本的最高五分位；
2. `depth` 处于同一历史样本的最低五分位；
3. `vol_ratio < 1`。

**实时性规则**：

- 对决策周 `w`（周末端 `d`），阈值只使用 `w_end < d` 的历史候选周，覆盖全 PIT 池；
- **禁止**全样本静态五分位；
- 历史不足 → `unclassifiable`，不进入 C 类；
- 历史下限：至少 **500 个历史候选周**、来自至少 **50 个 episode**；否则不可分类（实施下限，预注册，未验证）；
- 记录每个决策日的分位阈值序列。

**降级顺序（预注册）**：

1. 去掉条件 3（量能）；
2. 若仍不足 500 episode，把条件 2 放宽为 `depth ≤ 历史中位数`；
3. 若仍不足，报告“C 样本不足，结论不成立”，不再放宽。

### 6.4 三类允许重叠

A/B/C 可重叠。主比较是“类别 vs 同 episode 的 B0”，不是三类互相比拼；三类之间比较必须注明重叠样本。

## 7. 结果变量

### 7.1 固定窗口与计数规则

| 变量 | 定义 |
|---|---|
| 入场 bar | 入场日的有效 bar，记为**第 1 个有效交易日** |
| `r20` | 第 20 个有效 bar 收盘 / 入场开盘 − 1 |
| `r60` | 第 60 个有效 bar 收盘 / 入场开盘 − 1 |
| `r120` | 第 120 个有效 bar 收盘 / 入场开盘 − 1 |
| 有效 bar | 该股票在该交易日有 bar；停牌日不计入，也不用前值填充 |
| 缺失 | 剩余有效 bar 不足时记缺失，不向前填充；2026 年附近尤其如此 |

**注意不对称**：`r60` 的窗口包含入场 bar（第 1 天）；首次触及计时从入场日之后（第 2 个有效 bar）开始，因为 T+1 下入场日不能卖出。两者规则不同，结果中必须注明。

### 7.2 60 日收益分布（核心指标）

设交易集合为 `T`，每笔交易 `i` 有权重 `w_i`，收益 `r_i = r60_i`：

| 指标 | 定义 |
|---|---|
| `W+` | `Σ_{r_i>0} w_i` |
| `W-` | `Σ_{r_i<0} w_i` |
| `W0` | `Σ_{r_i=0} w_i` |
| `win60_all` | `W+ / (W+ + W- + W0)`：**全部有效交易为分母，flat 计入** |
| `win60_nonflat` | `W+ / (W+ + W-)`：**剔除 flat** |
| `flat60` | `W0 / (W+ + W- + W0)` |
| `avg_win60` | `Σ_{r_i>0} w_i r_i / W+` |
| `avg_loss60` | `Σ_{r_i<0} w_i |r_i| / W-` |
| `payoff60` | `avg_win60 / avg_loss60`；`W- = 0` 时记缺失 |
| `expectancy60` | `Σ_i w_i r_i / Σ_i w_i` |
| `median_win60` | 盈利交易的收益中位数 |
| `median_loss60` | 亏损交易的亏损绝对值中位数 |
| `win_share_top1/5/10` | 盈利前 1%/5%/10% 的交易占全部正收益总额的比例 |
| `expectancy60_ex_top1` | 剔除盈利前 1% 交易后的加权平均收益 |

**主门槛使用 `win60_all`**，因为目标是真实重复交易的胜率，而不是剔除不赚钱交易后的条件胜率。`win60_nonflat` 与 `flat60` 同时报告。B0 使用完全相同的定义。

**均值与中位数必须同时报告**。若 `avg_win60` 远高于 `median_win60`、或 `win_share_top1` 很高，必须标注“盈亏比依赖极端右尾”。

### 7.3 首次触及实验

| 变量 | 定义 |
|---|---|
| `race10_60` | 60 日内先 +10% 还是先 −10%（条件分母 = 至少触及一侧且无歧义） |
| `race20_vs_neg10_60` | 60 日内先 +20% 还是先 −10% |
| `race20_60` | 60 日内先 +20% 还是先 −20%（次要） |

**计时起点**：入场日的下一交易日（T+1）；入场日盘中触及不计。

**四类结果**：

1. 上行先；
2. 下行先；
3. 两侧都未触及；
4. **同日歧义**：首次有效触及的同一根日 K 内，最高价与最低价同时越过两侧阈值，且此前两侧均未触及 → 单列 `ambiguous`，**不进入“上行先/下行先”分母**。

**注明**：触及不等于成交；跳空、涨跌停、日内顺序不明都会让理论触及价无法成交。阶段 2 只作辅助证据，不能替代 7.2。

### 7.4 风险指标

| 变量 | 定义 |
|---|---|
| `mae60` | 第 1 至第 60 个有效 bar 的最低价 / 入场开盘 − 1（含入场 bar） |
| `mdd60` | 第 1 至第 60 个有效 bar 的滚动峰值回撤最大值（负值） |

## 8. 对照与聚合

### 8.1 三层基线

| 基线 | 定义 | 用途 |
|---|---|---|
| **B0 同 episode 非类别候选周** | 同一 episode 内、**所有不满足该类别原始条件的候选周** | **主对照** |
| B1 信号周 | 该 episode 的信号周 | 辅助 |
| B2 全市场同期对照 C | 上游 C 组 | 仅参考，标注选择偏差 |

### 8.2 B0 的精确计算与类别标签（本版统一）

**每个候选周必须保留原始标签**：`label_A`、`label_B`、`label_C`（以及 `c_classifiable`）。标签是“该周是否满足该类别的原始条件”，与“是否被选为该类别的第一次观测”无关。

对 episode `e`、类别 `X`：

1. B0 集合 = episode 内所有 `label_X = False` 的候选周；
2. 每个 B0 周 `j` 必须能计算完整 `r60_j`；不完整者剔除，不插补；
3. 有效 B0 周数 `n_e ≥ 5`，否则整个 episode 不进入主配对样本；
4. **episode 内等权**：每个 B0 周权重 `1/n_e`，使每个 episode 的总权重为 1；
5. 类别侧：该 episode 的类别交易权重为 1；
6. **payoff60 统一按下式计算，两侧使用同一公式**：

```
payoff_X = ( Σ_{r_i>0} w_i r_i / Σ_{r_i>0} w_i )
         / ( Σ_{r_i<0} w_i |r_i| / Σ_{r_i<0} w_i )
```

其中类别侧 `w_i = 1`（每 episode 一笔）；B0 侧 `w_i = 1/n_e`。

**禁止**：先算每个 episode 的盈亏比，再对盈亏比取平均。

7. `win60_all`、`win60_nonflat`、`expectancy60` 同样按上述权重计算；B0 与类别侧分母定义完全一致；
8. `r60` 与 `win60_all` 可按 episode 配对（类别值 − B0 值）；`payoff60` 不按 episode 配对，而是按 6 的公式对同一批配对 episode 的两侧分别汇总；
9. Bootstrap：按 episode 重采样；同一批重采样 episode 同时重建两侧，再计算两侧 `payoff60`；日历序列另做 6 个月区块 bootstrap。

### 8.3 主要配对样本（本版新增）

只有同时满足以下条件的 episode 才进入**主要**统计：

1. 类别侧存在有效入场（非 `untradable`）；
2. 类别侧拥有完整 `r60`（第 60 个有效 bar 存在）；
3. B0 至少有 **5 个有效非类别候选周**；
4. 这 5 个（或更多）B0 候选周都能计算完整 `r60`。

**所有主成功指标——`win60_all`、`payoff60`、`expectancy60`、`r60` 配对差、`mae60`——都必须在这同一批配对 episode 上计算。**

类别侧使用全部样本的结果，只能作为**补充结果**另行报告，不得用于成功判据。否则会出现“类别侧用全部样本、B0 只用更长更健康的趋势”的不可比问题。

### 8.4 两种权重口径

| 口径 | 定义 | 用途 |
|---|---|---|
| **episode 等权（主）** | 每 episode 每类取第一次观测；episode 之间等权 | 主结论 |
| 事件等权（次） | 所有候选周，按 episode 聚类 bootstrap | 稳健性检查 |

两者方向不一致时标“不确定”，不挑有利口径。

## 9. 统计与多重检验（本版统一为 12 项）

| `win60_all` 相对 B0 的差异 | 1 | 3 | 胜率是否更高 |
| `payoff60` 相对 B0 的差异 | 1 | 3 | 盈亏比是否更高 |
| `expectancy60` 是否大于 0 | 1 | 3 | 绝对收益是否为正 |
| **合计** | **4** | **12** | |

- 12 项统一使用预注册的 **Benjamini–Hochberg** 校正，报告校正前后 p 值；
- `r60`、`win60_all`、`payoff60` 是相对检验；`expectancy60` 是绝对检验，两者回答不同问题，不互相替代；
- 其余指标为描述性，不作“发现”宣称；
- 样本量下限：每类至少 **500 个配对 episode** 才做主检验；不足则只报描述统计并标“样本不足”。

## 10. 预注册的成功 / 失败判据

### 10.1 一个类别被认定为“有进入时机优势”，必须同时满足

所有指标均在 8.3 的主要配对样本上计算。

1. 该类至少 **500 个配对 episode**；
2. `win60_all ≥ 50%`（episode 等权）；
3. `payoff60 ≥ 2.00`（episode 等权加权交易分布）；
4. `expectancy60 > 0`，且 episode 聚类 bootstrap 95% CI **不含 0**；
5. `r60` 的 episode 配对均值差 95% CI 不含 0，且中位差与均值差同号；
6. 合格完整年度中，**≥70% 的年度** `r60` 配对差为正；
7. `mae60` 中位不比 B0 差超过 **2 个百分点**（决策容忍度，不是数据参数）；
8. 事件等权口径下 `expectancy60` 点估计同号。

### 10.2 目标不可替代

- `win60_all ≥ 50%` 与 `payoff60 ≥ 2.00` 是**两个并列目标**；
- **不得**用 `expectancy60 > 0` 替代其中任何一个；
- 若 `win60_all ≥ 50%` 但 `payoff60 < 2.00`，或 `payoff60 ≥ 2.00` 但 `win60_all < 50%`，均判未达标；
- `win60_nonflat` 只作报告，不作主门槛；
- 若 `r60` 显著更好但 `mae60` 差超过 2pp、或 `q10_60` 显著更差，判为“**高收益伴随高风险**”，不能称为“低风险进入时机”。

### 10.3 失败判据

- 若没有任何类别同时满足 10.1 全部条件 → **在当前定义下，未发现可重复的进入时机优势**；
- 不得在看到结果后降低门槛、更换窗口、增加类别、或把“接近显著”当作成立；
- 若只有 A 类成立、B/C 不成立，如实报告，不强行让三类都下结论。

## 11. 年度统计口径

1. **完整年度**：2005–2025 共 **21 个**；
2. **2026 为 YTD**，单列报告，**不进入 21 年稳定性分母**；
3. 每年披露：配对 episode 数、类别观测数、`r60` 可评估数；
4. **合格年度**：该类别当年至少 **30 个配对 episode**；不足 30 的年份只展示，不进入稳定性统计；

6. 不得用只有几个事件的年份评价稳定性。

## 13. 已知偏差与限制

1. **趋势选择偏差仍在**：所有候选周都在已识别趋势内；只回答“趋势内部时机”。
2. **C 类天然条件于存活**：只有活到成熟期的趋势才有 C 候选周；样本构成与 A/B 不同。
3. **配对样本选择偏差（新增）**：要求完整 60 日与 B0 ≥5 周，会排除临近 2026-09-30 的 episode 与长期停牌股票。该过滤对类别侧与 B0 侧对称，但会改变样本构成；必须报告被排除 episode 数及年份分布。
4. **周频决策**：会漏掉周内更优进入点；日频不在本协议内。
5. **固定窗口可跨过 episode 终点**：有意设计；阶段 2 的 60 日持有不是未来交易的退出规则。
6. **触及不等于成交**：跳空、涨跌停、停牌、日内顺序不明；阶段 2 不模拟成交。
7. **数据缺口**：103 只 qfq 因子失败视为不可评估；右删失/截断单列；2026 YTD。
8. **B 的 `vol_ratio` 基线 12 周**：沿用既有口径，未验证。
9. **A 的确认延迟**：低点确认需右侧两根 K，A 的进入通常比低点晚约两周。
