# EP-02 最大回撤归因报告（55.60%）

- 口径：L2 主情景（100 万本金 / 20 仓 / 单笔 5% NAV / 基准成本 / ST 5% / 容量 0.5%）
- 数据：`l2_daily_nav.csv`、`l2_trades_b_main.csv`、`attr_monthly.csv`、`attr_market_proxy.csv`
- 本轮未修改策略、未做参数搜索

## 一、结论（先说结果）

1. **55.60% 不是一次下跌造成的，是两段叠加**：2008 年一段（-44.21%），2011-2012 年再一段（从 2010-11-10 局部高点再跌 -49.06%），最终在 2012-12-03 触底。
2. **回撤的本质是"高暴露 + 固定 61 bar 持有 + 无止损"**，不是某几只股票的问题：回撤窗口内前十大亏损股只占窗口净亏损的 49.9%，亏损分散在 306 笔交易里。
3. **真正让回撤拖了 5 年的是"上行参与不足"**：2008 年组合 -38.10%、市场代理 -58.79%（少亏）；但 2009 年市场 +165.99%，组合只 +27.99%。跌得少、涨得也少，净值再也回不到 2008-01 的高点。
4. **20 仓上限在回撤期并没有降低暴露**：窗口内月度平均利用率 67.8%，平均持仓 15.3/20；在 2010-11（局部顶）利用率 98.8%，2015-06 为 94.6%。仓位上限没有变成"风险刹车"。
5. **2015 股灾是独立的第二类风险**：-42.45% 几乎全部是持仓期盯市损失（该窗口已实现仅 -9.6 万），持仓在跌势里被 61 bar 规则强制拿着。

## 七、2015 股灾独立分析

| 项目 | 数值 |
|---|---|
| 峰值 / 谷值 | 10,778,849（2015-06-12）→ 6,203,415（2015-09-15） |
| 回撤 | **-42.45%（-4,575,434 元）** |
| 该窗口已实现盈亏（06-01~10-31） | 仅 -96,053 元 |
| 崩溃日跨期持仓 | 20 笔 |
| 崩溃日持仓的完整生命周期平均收益 | +11.26%（多数最终仍盈利） |

结论：2015 的回撤几乎全是**满仓被套期间的盯市损失**，不是平仓实现亏损；净值在 2015-10 后修复（2015 年平仓实现 +2,363 万元）。但这恰恰说明：**如果投资者在 2015-09 被迫赎回，会实打实损失 42%**。这是"无止损 + 满仓 + 61 bar 固定持有"的直接后果，而不是行情噪声。

## 八、回撤归因结论

1. **主因**：组合在牛市末期处于 70%-99% 的高暴露，B 类信号在市场顶部密集出现；转入下跌后，61 bar 固定持有 + 无止损使组合无法减仓，只能吃下 2008 与 2011-2012 两段主跌（合计 -55.60%）。
2. **放大器**：上行捕获率只有 0.51。2009 年市场 +166%，组合仅 +28%，导致回撤持续 5 年而非 1 年。
3. **不是主因**：单票集中度（前十大亏损占 49.9%，但单只最大仅 5.8%）、退出延迟（0.54%）、资金利用率（与月度收益相关 ≈ 0）、20 仓上限（窗口内很少打满，未起到减仓作用）。
4. **2015 是第二类风险**：满仓 + 固定持有 → -42.45% 盯市回撤，虽然最终修复，但过程中的赎回风险不可忽视。
