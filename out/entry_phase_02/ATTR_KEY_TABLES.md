## 表 7 数据文件清单

| 文件 | 内容 |
|---|---|
| `attr_summary.json` | 汇总（筛选偏差、回撤、2015、利润集中度、最差月份） |
| `attr_extra.json` | 回撤两段拆分、年末净值、beta/捕获率、相关性 |
| `attr_monthly.csv` | 逐月净值/收益/持仓/利用率/新开/平仓/市场代理/回撤 |
| `attr_market_proxy.csv` | 等权全市场代理日收益与指数（**非交易所指数**） |
| `attr_selection_metrics.csv` | 成交 vs 未成交 20/60 日指标 |
| `attr_selection_by_year.csv` | 分年份成交/未成交均值 |
| `attr_selection_by_congestion.csv` | 按同日信号数分桶 |
| `attr_selection_by_regime.csv` | 按信号前 60 日市场阶段分桶 |
| `attr_stock_pnl_2008_2012.csv` | 回撤窗口个股盈亏（含板块） |
| `attr_board_pnl_2008_2012.csv` | 回撤窗口板块盈亏 |
| `attr_cohort_pnl.csv` | 按入场月份的已实现盈亏 |
| `attr_pnl_by_exit_year.csv` | 按平仓年份的已实现盈亏 |
| `attr_stock_pnl_2015.csv` | 2015-06~10 个股盈亏 |
