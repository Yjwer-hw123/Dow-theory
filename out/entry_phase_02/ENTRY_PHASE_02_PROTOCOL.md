## 1. 研究目标

基于 ENTRY-PHASE-01 v1.2 阶段 2 的 A/B 候选信号，回答一个问题：

> 每当该信号出现，按 A 股真实交易制度投入资金，扣除全部成本后长期重复执行，账户能否实现正收益、且不过度依赖少数极端交易或少量年份？

### 1.1 评价原则（替代原 50% 胜率 / 2:1 盈亏比硬门槛）

| 评价项 | 原则 |
|---|---|
| 胜率 | 不设绝对门槛 |
| 盈亏比 | 不设绝对门槛 |
| 净期望值 | 必须 > 0，且 bootstrap 置信区间不含 0 |
| 极端盈利依赖 | 剔除净盈利前 1% 后仍须 > 0 |
| 年度稳定性 | 多数完整年度净收益为正 |
| 组合回撤 | 必须处于预先声明的可接受范围 |
| 实际成交 | 必须通过 T+1、停牌、涨跌停、跳空、滑点检验 |
| 归因 | 单一股票 / 单一年度不得主导总利润 |

### 1.2 本轮不做的事

- 不搜索参数，不优化 60 日持有期；
- 不增加均线、MACD、形态或其他过滤；
- 不改 A/B 原始定义与缩量口径；
- 不根据结果删除亏损交易或挑选有利成本情景；
- 不把同一段历史回测宣称为独立样本外验证。

## 4. 交易执行模拟

### 4.1 买入

1. 候选周最后交易日之后的**下一有效交易日开盘**买入。
2. 若该日无 bar（停牌）或开盘即涨停不可买，顺延到下一有效交易日开盘。
3. 顺延上限 **10 个市场交易日**；超过则记为 `untradable_entry`，不进入收益统计，但必须计入失败率。
4. 买入价 = 当日原始开盘价 × (1 + 买入滑点)。
5. 数量 = `floor(资金槽位 / 买入价 / 100) × 100`，最少 100 股；不足 100 股记 `untradable_size`。

### 4.2 持有与退出（第一版固定期限）

- 研究基准：第 **60 个有效交易日**（入场 bar 记为第 1 个有效 bar）收盘价退出，记 `exit_benchmark_close`。
- **可执行基准（主口径）**：第 60 个有效交易日之后的**下一有效交易日开盘**卖出，记 `exit_next_open`。
- 两种口径都必须报告；**验收判定使用可执行口径**。
- 若下一有效交易日开盘即跌停不可卖或无 bar：顺延至下一可成交交易日开盘，最多 10 个市场交易日；超过则记为 `delayed_close`，按第一个可成交价强制平仓并单独披露，**不得丢弃**。
- 卖出价 = 实际成交开盘价 × (1 − 卖出滑点)。
- T+1：入场当日不得卖出；本协议固定持有 60 个有效 bar，T+1 仅在异常强制平仓路径下需要校验。

### 4.3 涨跌停与不可成交判定

| 市场/期间 | 涨跌幅限制 |
|---|---|
| 主板（2005-01-01 起） | ±10% |
| 创业板（2009-10-30 起） | ±10%；2020-08-24 起 ±20% |
| 科创板（2019-07-22 起） | ±20% |
| 北交所（2021-11-15 起，若在池内） | ±30% |
| ST 股 | 名义 ±5%，但本地数据无 ST 标记，**无法可靠识别**（见第 10 节限制） |

判定规则：

- 涨停价 / 跌停价按前收盘价与当日适用比例计算，价格按 0.01 元最小变动单位取整；
- 买入日：`开盘价 ≥ 涨停价 − 0.005` 视为开盘封涨停、不可买，顺延；
- 卖出日：`开盘价 ≤ 跌停价 + 0.005` 视为开盘封跌停、不可卖，顺延；
- 开盘未封板但盘中触及涨跌停的，开盘仍可成交，不视为失败；
- 无 bar（停牌）一律视为不可成交，按 4.1 / 4.2 顺延；
- 新股上市首日及交易所特别规则日：不剔除，但单独标记并披露。

> 全部规则以交易所公告为准；实现前须核对第 12 节清单。

### 4.4 跳空与滑点

- 跳空由“次日开盘成交”自然体现，不使用收盘价假设成交；
- 滑点按情景施加在成交价上（见 5.4），买入向上、卖出向下；
- 另记录 `delay_cost = 实际退出收益 − 第 60 日收盘基准收益`，用于量化延迟成交与跳空的代价。

## 5. 历史费用模型（日期有效，禁止统一套用现代费率）

### 5.1 佣金（买卖双边）

| 生效区间 | 费率（每边） | 最低收费 |
|---|---|---|
| 2005-01-01 – 2015-04-30 | 0.30%（法定上限口径） | 5 元/笔 |
| 2015-05-01 – 至今 | 0.03% | 5 元/笔 |

### 5.2 印花税（按日期切换，卖方/双边不同）

| 生效区间 | 费率 | 征收方向 |
|---|---|---|
| 2005-01-01 – 2007-05-29 | 0.10% | 买卖双边 |
| 2007-05-30 – 2008-04-23 | 0.30% | 买卖双边 |
| 2008-04-24 – 2008-09-18 | 0.10% | 买卖双边 |
| 2008-09-19 – 2023-08-27 | 0.10% | 仅卖方 |
| 2023-08-28 – 至今 | 0.05% | 仅卖方 |

### 5.3 过户费

| 生效区间 | 费率 | 范围 |
|---|---|---|
| 2005-01-01 – 2015-07-31 | 0.002% / 边 | 仅沪市 |
| 2015-08-01 – 至今 | 0.002% / 边 | 沪深统一 |

若期间存在下调公告，按公告实际值执行并在实现说明中记录差异；量级对结论影响可忽略，但必须可追溯。

### 5.4 滑点与三情景

| 情景 | 滑点（每边） | 用途 |
|---|---|---|
| 基准 | 10 bp | **主判定** |
| 保守 | 20 bp | 稳健性，必须同号 |
| 压力 | 30 bp，另对全部费率 +20% | 仅披露，不参与主判定 |

三情景全部报告；**不得在看到结果后挑选最有利情景作为结论**。主判定预先锁定为“基准”。

### 5.5 单笔净收益定义

```
买入总额 = 买入价 × 股数
买入费用 = max(佣金率 × 买入总额, 5) + 过户费
卖出总额 = 卖出价 × 股数
卖出费用 = max(佣金率 × 卖出总额, 5) + 过户费 + 印花税
净收益 = (卖出总额 − 卖出费用 − 买入总额 − 买入费用) / (买入总额 + 买入费用)
毛收益 = 卖出总额 / 买入总额 − 1
成本拖累 = 毛收益 − 净收益
```

成本在成交时逐笔扣除，不做年度平均摊销。

## 6. 资金、重叠与组合账本

### 6.1 两套账本（A、B 各自独立）

| 账本 | 用途 |
|---|---|
| 无限资金逐笔账 | 全部可成交信号各一笔，用于逐笔统计与主期望判定 |
| 限额组合账 | 模拟真实资金约束，用于净值、回撤、资金占用 |

### 6.2 限额组合规则（预先固定，不调）

- 初始资金 1,000,000 元，归一化处理；
- 最大同时持仓 **20 笔**，单笔目标资金 **5%**（即 100% 资金上限，无杠杆）；
- 同一股票在持仓期间再次触发信号：**不加仓**，记 `overlap_skip`；
- 同一 episode 只取第一笔，防止同趋势重复；
- 当可用槽位不足时，按“候选周结束日早→股票代码小”的确定性顺序成交，其余记 `queue_reject`，不得事后替换；
- 单笔名义金额不得超过入场日成交额的 **0.5%**（流动性上限），超出则按上限缩减股数；
- 现金不计利息，不做再平衡，不做止损/止盈（第一版只做固定 60 日退出）。

### 6.3 组合净值

- 每日按收盘价盯市；停牌股按最后可得收盘价挂账；
- 净值序列覆盖 2005-01-01 至最后完整数据日；
- 最大回撤按日频净值计算（含成本）；
- 记录每日持仓数、资金占用率、单股最大权重。

## 7. 统计指标

### 7.1 逐笔

- 笔数、可成交率、不可成交原因分布（停牌/涨停/超期/零股）；
- 毛收益、净收益、成本拖累；
- 净胜率、平均净盈利、平均净亏损、净盈亏比、净期望；
- 盈利中位数、亏损中位数；
- **中位数收益结构指标**（用净胜率与净盈利/亏损中位数构造的描述量，不得称为严格期望）；
- 剔除净盈利前 1% 后的净期望；
- 盈亏集中度：最高 1%/5%/10% 盈利交易占总净盈利比例；
- 延迟退出笔数、强制平仓笔数、延迟成本。

### 7.2 年度

- 每个完整年度（2005–2025）的**绝对净收益**（不是相对 B0 的差）；
- 年度胜率、年度交易笔数、年度最大回撤；
- 2026 YTD 单列，不进入年度比例分母。

### 7.3 组合

- 累计收益、年化收益（CAGR）、最大回撤、夏普（日频，无风险利率 0，仅披露）；
- 年度净收益与年度为正比例；
- 平均/最大持仓数、最大资金占用；
- 信号重叠数、队列拒绝数、单股/单年利润贡献占比；
- 净值曲线与回撤曲线导出。

### 7.4 置信区间

- 以 **episode** 为重采样单位做 bootstrap（1000 次，固定随机种子），避免把同一趋势的多笔交易当作独立样本；
- 主期望、净胜率、盈亏比、年度收益均给出 95% 区间。

## 8. 验收与失败标准（预注册，评审通过后不得改动）

主判定使用：**基准成本 + 可执行次日开盘退出 + 限额组合账（B 类）**。

### 8.1 通过条件（须全部满足）

| 编号 | 条件 |
|---|---|
| P1 | 有效成交笔数 ≥ 500 |
| P2 | 净期望 > 0，且 95% bootstrap 置信区间下限 > 0 |
| P3 | 剔除净盈利前 1% 后净期望 > 0 |
| P4 | 完整年度（2005–2025）净收益为正的比例 ≥ 60% |
| P5 | 组合最大回撤 ≤ 30% |
| P6 | 不可成交与超期强制平仓合计 ≤ 5%，且逐笔可追溯 |
| P7 | 单一股票贡献 ≤ 20% 总净盈利；单一年度贡献 ≤ 50% |
| P8 | 基准与保守成本情景净期望同号 |

### 8.2 失败条件（任一触发）

- 净期望 ≤ 0，或置信区间包含 0；
- 剔除净盈利前 1% 后净期望 ≤ 0；
- 有效成交笔数 < 500；
- 组合最大回撤 > 40%；
- 单一股票贡献 > 30% 或单一年度贡献 > 60%。

### 8.3 情景规则

- 压力情景仅披露；若压力下净期望转负，结论必须标注“成本敏感”，不得据此宣称通过。
- A 类使用**完全相同**的规则与门槛，单独裁定，不因 B 的结果放宽或收紧。

## 10. 已知限制（必须在最终报告中披露）

1. 本地数据缺少 ST 标记，无法按 ±5% 识别 ST 涨跌停，可能低估封板与不可成交率。
2. 仅有日线，无法模拟盘中排队、封单量与真实成交概率；本协议用“开盘价 + 滑点”作为保守近似。
3. 复权因子来自公开接口，若持有期内有分红/送转，收益按 qfq 折算，可能与实际账户现金流存在细微差异。
4. 无行业、市值、流动性分层；0.5% 成交额上限只是粗略流动性约束。
5. 2005 年早期数据质量、退市股与代码变更可能带来偏差；股票池已含退市股，但仍可能有缺失。
6. 60 日固定持有是执行性基准，不代表最优持有期；本阶段不优化。
7. 费用表若与公告有差异，以公告为准并记录，不得据结果反向调整。
