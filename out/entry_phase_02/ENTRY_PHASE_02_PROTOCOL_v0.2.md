## 1. 研究目标

回答：B（缩量调整）与 A（第一次确认回撤）在 A 股真实制度与成本下，按固定 60 个有效交易日持有，扣除全部成本后能否稳定盈利。

### 1.1 评价原则

| 评价项 | 原则 |
|---|---|
| 胜率 / 盈亏比 | 不设绝对门槛 |
| 净期望 | > 0，且 episode 级 bootstrap 95% CI 下限 > 0 |
| 极端盈利依赖 | 剔除净盈利前 1% 后仍 > 0 |
| 年度稳定性 | 完整年度（2005–2025）绝对净收益为正的比例 ≥ 60% |
| 组合回撤 | 日频净净值最大回撤 ≤ 30% |
| 集中度 | 单股正贡献 ≤ 20%，单年正贡献 ≤ 50% |
| 执行 | 入场失败率 ≤ 5%；退出延迟率 ≤ 10%；期末未平仓单独披露 |
| 成本稳健 | 基准与保守情景净期望同号 |

### 1.2 不做的事

不优化参数、持有期、缩量比例；不加均线/指标/形态；不改 A/B 定义；不按结果删交易或挑成本情景；不把同一段历史称为样本外验证。

## 4. 交易执行

### 4.1 买入

1. 候选周最后交易日之后的**下一有效交易日开盘**买入。
2. 无 bar（停牌）或开盘即涨停不可买 → 顺延，最多 **10 个市场交易日**（沿用 EP-01 入场有效期）。
3. 超过 10 日 → `fail_entry_timeout`，计入入场失败。
4. 买入价 = 原始开盘价 × (1 + 单边滑点)。
5. 股数 = `floor(仓位金额 / 买入价 / 100) × 100`；不足 100 股 → `fail_entry_size`。
6. 仓位金额 = min(买入时组合净资产 × 5%, 容量上限)；容量上限见 4.5。

### 4.2 持有与退出

- 研究基准：第 60 个有效交易日收盘（入场 bar 为第 1 个有效 bar），记 `exit_benchmark_close`。
- **判定口径（可执行）**：第 60 个有效交易日之后的**下一有效交易日开盘**卖出。
- 若该日无 bar 或开盘跌停不可卖：**不设强制成交期限**，逐日等待至第一个真实可成交的交易日开盘。
- 记录：实际退出日、延迟市场交易日数、相对基准的额外盈亏、期间占用资金。
- 若数据截止仍未成交：记为 `open_at_data_end`，按最后可得收盘价计算未实现盈亏，计入组合净值，单列披露，**不得假设成交**。
- 若持有期内退市/长期停牌：按最后可成交价退出并标记 `delist_or_suspend_exit`；若无法取得可靠退市规则，单列且不进入主判定样本。
- T+1：入场当日不得卖出；固定 60 bar 路径下不触发，异常退出路径必须校验。

### 4.3 涨跌停判定

按“证券类别 × 交易所 × ST 状态 × 生效日期”计算限价，不通过“当日涨跌幅接近 10%”反推。

| 证券类别 | 期间 | 涨跌幅 |
|---|---|---|
| 沪深主板普通股 | 2005-01-01 起 | ±10% |
| 沪深主板 ST/*ST | 2005-01-01 起 | ±5% |
| 创业板普通股 | 2009-10-30 – 2020-08-23 | ±10% |
| 创业板普通股 | 2020-08-24 起 | ±20% |
| 创业板 ST | 2009-10-30 – 2020-08-23 | ±5% |
| 创业板 ST | 2020-08-24 起 | ±20% |
| 科创板 | 2019-07-22 起 | ±20% |
| 北交所 | 2021-11-15 起 | ±30%（若在池内） |
| 科创板/创业板注册制新股 | 上市前 5 个交易日 | 无涨跌幅限制 |
| 主板注册制新股 | 2023-04-10 起，上市前 5 个交易日 | 无涨跌幅限制 |
| 退市整理期 / 重新上市 / 复牌特殊日 | 按交易所当期规则 | **待核实**，标记 `special_regime` |

判定：

- 限价 = `round_half_up(原始前收盘 × (1 ± 比例), 2)`，最小变动 0.01 元；
- 买入：`开盘价 ≥ 涨停价 − 0.005` → 不可买，顺延；
- 卖出：`开盘价 ≤ 跌停价 + 0.005` → 不可卖，顺延；
- 开盘未封板、仅盘中触及 → 开盘可成交，不视为失败；
- ST 历史状态缺失时不得默认 ±5% 或 ±10%；实现前必须先补齐（见第 11 节），否则只能声明为“±10% 近似”，不得宣称完成制度模拟。

### 4.4 滑点

| 情景 | 单边滑点 |
|---|---|
| 基准 | 10 bp |
| 保守 | 20 bp |
| 压力 | 30 bp |

买入向上、卖出向下，各自计算。滑点不替代涨跌停规则。

### 4.5 容量限制（禁止未来数据）

- 计算窗口：**信号日之前 20 个有效交易日**的日成交额算术均值，不含信号日与买入日。
- 上限 = 该均值 × 0.5%。
- 仓位金额 = min(净资产 5%, 上限)；若上限更紧，记 `capacity_capped` 并记录缩减比例。
- 买入日当天最终成交额**不得**用于开盘买入资格判断，只允许事后做容量校验。

## 5. 历史费用模型

### 5.1 佣金（三情景，均为“含规费”综合佣金）

| 情景 | 费率/边 | 最低收费 | 依据性质 |
|---|---|---|---|
| 基准 | 0.030% | 5 元/边 | 研究假设（可协商佣金，含经手费/证管费） |
| 保守 | 0.100% | 5 元/边 | 研究假设 |
| 压力 | 0.300% | 5 元/边 | 证监发〔2002〕21号法定上限（2002-05-01 起） |

- **不存在 2015-05-01 全国佣金费率调整的可靠依据**；v0.1 的该分段已删除，统一按情景费率，不虚构历史实际费率。
- 3‰ 只是法定上限，不得表述为“历史实际佣金”。
- 最低 5 元/边必须逐笔计入；小额仓位会显著抬高成本。
- 佣金按证监发〔2002〕21号为含规费口径：**经手费、证管费已包含在内，不另行加收**。
- 经手费仅作交叉校验（见 5.4）；若某情景费率低于当期经手费，应报错并人工复核，而不是叠加。

### 5.2 印花税

| 生效区间 | 税率 | 方向 | 状态 |
|---|---|---|---|
| 2005-01-01 – 2005-01-23 | 1‰ | 双边 | **待核实**（沿用前期税率） |
| 2005-01-24 – 2007-05-29 | 1‰ | 双边 | 已核对 |
| 2007-05-30 – 2008-04-23 | 3‰ | 双边 | 已核对 |
| 2008-04-24 – 2008-09-18 | 1‰ | 双边 | 已核对 |
| 2008-09-19 – 2023-08-27 | 1‰ | 卖方单边 | 已核对 |
| 2023-08-28 – 至今 | 0.5‰ | 卖方单边 | 已核对 |

### 5.3 过户费

| 生效区间 | 沪市 | 深市 | 状态 |
|---|---|---|---|
| 2005-01-01 – 2012-05-31 | 按面值计费；本模型近似 **0.001 元/股**（保守 0.002 元/股） | 0 | **待核实**（缺面值/规则原文） |
| 2012-06-01 – 2015-07-31 | 成交金额 0.002%/边 | 0 | 已核对调整时点，费率口径待公告复核 |
| 2015-08-01 – 2022-04-28 | 沪深统一 0.002%/边 | 同左 | 已核对 |
| 2022-04-29 – 至今 | 沪深统一 0.001%/边 | 同左 | 已核对 |

过户费按边收取；2005–2012 的近似必须在报告中单列误差敏感度。

### 5.4 交易经手费（仅校验，不叠加）

| 生效日期 | 沪深水平 |
|---|---|
| 2012-06-01 | 0.087‰ |
| 2012-09-01 | 0.0696‰ |
| 2015-08-01 | 0.0487‰ |
| 2023-08-28 | 0.0341‰ |

用途：确认“基准佣金 0.030%”高于同期经手费量级；**不得**在佣金之外再加。

### 5.5 单笔净收益

```
买入总额 = 买入价 × 股数
买入费用 = max(佣金率 × 买入总额, 5) + 过户费
卖出总额 = 卖出价 × 股数
卖出费用 = max(佣金率 × 卖出总额, 5) + 过户费 + 卖方印花税
净收益 = (卖出总额 − 卖出费用 − 买入总额 − 买入费用) / (买入总额 + 买入费用)
毛收益 = 卖出总额 / 买入总额 − 1
成本拖累 = 毛收益 − 净收益
```

### 5.6 情景规则

- 主判定锁定**基准**情景。
- 压力情景只调整佣金假设与滑点（3‰、30 bp），**不提高**法定印花税与过户费。
- 三情景全部报告；不得在看到结果后改选。

## 6. 资金与组合

### 6.1 账本

| 账本 | 用途 |
|---|---|
| 无限资金逐笔账 | 全部可成交交易，主期望/集中度判定 |
| 限额组合账 | 净值、回撤、资金占用、年度绝对收益 |

### 6.2 基准配置

- 每账本初始资金：**1,000,000 元**；
- 最大同时持仓 **20 笔**；
- 单笔目标 = 买入时**组合最新净资产**的 **5%**（分母含现金与按最后收盘价盯市的持仓）；
- 无杠杆、不加仓、不做再平衡、现金零利息；
- 持仓不足 20 笔时保留现金。

### 6.3 同日多信号排序

- 排序键：`SHA256(seed | 候选周结束日 | 股票代码)`，升序；
- 固定种子 `seed = 20261107`，写入运行记录；
- 目的：可复现，且避免股票代码前缀造成系统性选择偏差；
- 槽位不足者记 `queue_reject`，不得事后替换；
- 已持有同一股票 → `overlap_skip`。

### 6.4 净值与盯市

- 每日收盘盯市；停牌按最后可得收盘价；
- 未平仓头寸按盯市价计入净值与回撤；
- 净值序列覆盖 2005-01-01 至最后完整数据日。

## 7. 统计指标与精确定义

### 7.1 逐笔

笔数、毛/净收益、成本拖累、净胜率、平均净盈利/亏损、净盈亏比、净期望、盈利/亏损中位数、**中位数收益结构指标**（描述量，不称期望）、剔除净盈利前 1% 后的净期望、盈利集中度（最高 1%/5%/10% 正收益占总净盈利比例）。

### 7.2 年度绝对收益

- 年度收益 = 该年度日频组合净值首尾复合收益（含未实现盈亏、已扣成本）；
- 分母固定为 **2005–2025 共 21 个完整年度**；
- 无交易的年份计 0 收益，计入分母，但**不计为盈利年度**；
- 2026 YTD 单列，不进入分母。

### 7.3 最大回撤

`MDD = max_t (峰值净值 − 当前净值) / 峰值净值`，基于限额组合账的日频净净值（含未实现盈亏）。

### 7.4 集中度

```
C_stock = max_s(PnL_s^+, 0) / Σ_s PnL_s^+
C_year  = max_y(PnL_y^+, 0) / Σ_y PnL_y^+
```

其中 `PnL^+` 只取正净收益。单股 ≤ 20%，单年 ≤ 50%。

### 7.5 执行失败（分开统计）

| 指标 | 分母 | 说明 |
|---|---|---|
| 入场失败率 | 全部合格类别信号数 | 含停牌/涨停/超期/零股，按原因分列 |
| 退出延迟率 | 已成交笔数 | 延迟 ≥1 个市场交易日 |
| 期末未平仓率 | 已成交笔数 | 数据截止仍未平仓 |
| 容量缩减率 | 已成交笔数 | `capacity_capped` |

### 7.6 置信区间

以 episode 为重采样单位，1000 次 bootstrap，固定种子；不把同一趋势内多笔交易当作独立样本。

## 8. 验收与失败标准（预注册）

主判定：基准成本 + 可执行退出 + 限额组合账，B 类；A 类同规则独立裁定。

### 8.1 通过条件（全部满足）

| 编号 | 条件 |
|---|---|
| P1 | 有效成交笔数 ≥ 500 |
| P2 | 净期望 > 0 且 95% CI 下限 > 0 |
| P3 | 剔除净盈利前 1% 后净期望 > 0 |
| P4 | 2005–2025 中绝对净收益为正的年度比例 ≥ 60%（分母固定 21 年，零交易年计 0） |
| P5 | 限额组合账日频 MDD ≤ 30% |
| P6 | 入场失败率 ≤ 5%；退出延迟率 ≤ 10%；期末未平仓率单独披露且 ≤ 0.5% |
| P7 | C_stock ≤ 20%，C_year ≤ 50% |
| P8 | 基准与保守情景净期望同号 |

### 8.2 失败条件（任一）

净期望 ≤ 0 或 CI 含 0；剔除前 1% 后 ≤ 0；成交笔数 < 500；MDD > 40%；C_stock > 30%；C_year > 60%。

### 8.3 情景

压力情景仅披露；若转负，结论标注“成本敏感”，不据此宣称通过。

## 9. 样本外与可复现性

2005–2026 均已被 EP-01 观测，**不构成独立样本外验证**；本阶段只证明历史执行可行性。真正验证须协议冻结后做 ≥12 个月前瞻模拟/纸面交易，另行立项。全部逐笔、失败原因、成本分解、净值曲线落盘，带参数与种子；代码变更重跑且保留旧结果。

## 10. 已知限制

1. ST 历史状态缺失 → 无法可靠识别 ±5% 与创业板 ST 规则；实现前必须补齐，否则只能近似并披露。
2. 仅有日线，无法还原封单队列与成交优先级；“开盘价 + 滑点”是近似成交模型。
3. 退市整理期、重新上市、复牌特殊日、新股无涨跌幅期的完整历史规则尚未全部取得。
4. 2005–2012 沪市过户费规则与费率待核实，采用近似值。
5. 分红/送转以复权因子折算，与真实账户现金流可能存在细微差异。
6. 无行业/市值/流动性分层；容量上限只是粗略约束。
7. 60 日固定持有是执行基准，不优化。
