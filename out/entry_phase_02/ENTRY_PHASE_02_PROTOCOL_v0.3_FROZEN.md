## 1. 研究目标（两层，不得混算）

本阶段不是建设完美的交易所历史仿真系统，而是回答一个可证伪的问题：**A 股全市场的 B 类入场信号，扣除合理交易成本后，能否长期赚钱？**

| 层次 | 要回答的问题 | 允许的简化 | 通过后才做的事 |
|---|---|---|---|
| **第一层 L1：策略盈利性** | B 类入场扣除合理交易成本后是否仍赚钱 | 逐笔等额账本、无限资金、不做跌停/封单/容量模拟 | 才值得投入第二层 |
| **第二层 L2：实际可交易性** | 加入涨跌停、停牌、资金占用、容量后是否还能赚钱 | 日线保守成交代理（不可还原封单） | 才值得讨论仓位与组合 |

硬规则：

1. **L1 不通过，不启动 L2**。不得用 L2 的复杂模拟去掩盖 L1 的负期望。
2. L1 与 L2 的结果必须**分开报告**，不得合并成一个"综合收益"。
3. 任何一层都不得以"通过"表述，除非该层验收条款全部满足。

## 2. 数据基础与可用性前置条件

### 2.1 价格与复权

- 收益计算**必须**使用前复权序列 `cache/qfq/{code}.parquet`。
- 复权口径：`qfq(t) = raw(t) / f`，`f` 为最后一个 `d ≤ t` 的累计因子（新浪 `qfq.js` 端点，已实证）。
- `volume` 按 `f` 放大（等效股数）；`amount` 保持原值（成交额是真金白银，不随复权变化）。
- **成本计算必须回到原始价**：`raw_price = qfq_price × f`。因为沪市过户费按成交面额（股数）计，股数取决于原始价。

### 2.2 复权覆盖率（L1 的硬前置）

| 指标 | 门槛 | 不达标处理 |
|---|---|---|
| 全池复权因子覆盖率 | ≥99%（5,555 只中 ≥5,500 只） | **不得启动 L1 主判定** |
| 不可复权区间占比（股票 × 交易日） | ≤1% | 超过则缩样本重做，并在报告披露 |
| 不可复权区间 | 必须标 `not_computable` | 不得以任何折扣替代、不得当作正常收益 |

复权失败或无法核验的股票区间一律 `not_computable`，从 L1 分子分母中剔除并单列占比。**不使用"简单保守折扣"替代**：除权跳空会同时扭曲收益与胜率，折扣无法修正方向。

### 2.3 成交额

- `amount = volume × close`，为**近似成交额**，全流程标记 `ADV_APPROX`。
- 仅用于容量约束，不得用于任何收益或流动性结论。
- 报告中不得表述为"交易所真实成交额"。

### 2.4 历史 ST 状态

- 本地 PIT 覆盖率为 **0%**（见 `EP02_ST_EVIDENCE_COVERAGE.md`）。
- 所有无法确认状态的 `(股票, 交易日)` 标 **`ST_UNKNOWN`**。
- 处理方式见 §5.3，**不得默认 10%，也不得删除后称全池结果**。

### 2.5 数据末日

- 各股票以缓存最后一根 bar 为数据末日（抽查为 2026-09-30，运行日 2026-11-07）。
- 数据截止仍未平仓的头寸按最后收盘价估值，单列，不认定为已实现收益。

## 4. 第一层 L1：策略盈利性

### 4.1 账本与样本

| 项 | 规定 |
|---|---|
| 账本 | 逐笔等额账本：每笔投入 1 个货币单位，无限资金，无仓位上限 |
| 样本 | EP-01 冻结口径下的 B 类配对 episode（`n_paired ≥ 5` 的同 episode B0 对照保留用于描述，不进入 L1 判定） |
| 价格 | 前复权 `qfq` |
| 复权不可计算 | 剔除并单列 `not_computable` |
| 不做 | 涨跌停封单、停牌顺延、容量、资金占用、组合净值 |

### 4.2 入场与退出

- 入场：信号周结束后，**下一有效交易日开盘价** + 滑点（买入加）。
- 无 bar 顺延最多 10 个市场交易日；超限记 `entry_fail`（L1 中仅作披露，不作为筛选）。
- 退出：入场 bar 为第 1 个有效 bar，**第 60 个有效 bar 收盘价** − 滑点（卖出减）。
- L1 **不模拟**跌停卖不出、停牌、退市整理等执行障碍；这些属于 L2。

### 4.3 成本（只扣合理成本，不做压力表演）

三情景，全部**单边**：

| 情景 | 佣金（含规费） | 滑点 | 印花税 | 过户费 |
|---|---|---|---|---|
| 基准 | 0.030%/边，最低 5 元 | 10 bp | 法定分段，仅卖出 | 法定分段 |
| 保守 | 0.100%/边，最低 5 元 | 20 bp | 同上 | 同上 |
| 压力 | 0.300%/边，最低 5 元 | 30 bp | 同上 | 沪市按上界；2012-06–2015-07 券商留存 ×2 |

- 压力情景**只调佣金与滑点**，不得抬高法定印花税/过户费。
- 买入：`金额×(1+佣金率+滑点率) + 沪过户费`；卖出：`金额×(1−佣金率−滑点率−印花税率) − 沪过户费`。
- 过户费面额口径：`股数 × 1 元 × 费率`，`股数 = 原始成交金额 / raw_price`，最低 1 元/边。
- 滑点为**单边**：买入加、卖出减，往返合计 2×。

### 4.4 指标（三项新增，必须单列）

1. **年度实际净收益**：L1 用逐笔等额累计净值曲线 `NAV_t = 1 + Σ(前 t 笔净收益率)`；年度净收益率 = 年末 NAV / 年初 NAV − 1；分母固定 **2005–2025 共 21 年**，零交易年计 0 但不计为盈利年度；2026 YTD 单列。
2. **每笔交易净收益中位数**：扣成本后的逐笔净收益率中位数，用于判断"是否只有少数大赢家"。
3. **连续亏损与资金回撤**：最长连续亏损笔数、基于上述 NAV 曲线的最大回撤 `MDD_L1`。

另报：净胜率、净盈亏比、净期望、剔除前 1% 后净期望、盈利集中度、成本拖累（毛收益 − 净收益）。

### 4.5 L1 验收（核心项否决，参考项不否决）

**核心项（全部满足才算 L1 通过）**

| 编号 | 条件 |
|---|---|
| L1-1 | 有效成交笔数 ≥ 500 |
| L1-2 | 净期望 > 0 且 95% CI 下限 > 0（episode 为 bootstrap 单位，1000 次，固定种子） |
| L1-3 | 剔除净盈利前 1% 后净期望 > 0 |
| L1-4 | 2005–2025 中年度净收益为正的比例 ≥ 60%（分母 21 年，零交易年计 0） |
| L1-5 | 每笔净收益中位数 > 0 |
| L1-6 | `MDD_L1 ≤ 30%`，最长连续亏损 ≤ 12 笔 |

**参考项（只披露，不否决）**：净胜率、净盈亏比、盈利集中度（top1/top5/top10）、成本拖累占比、与 B0 的相对优势。

**L1 失败（任一）**：净期望 ≤ 0 或 CI 含 0；剔除前 1% 后 ≤ 0；年度正比例 < 60%；中位数 ≤ 0；`MDD_L1 > 40%` 或最长连续亏损 > 20 笔。

> 说明：不再要求"八项全部满足"才承认方法价值。payoff 与相对 B0 优势只作参考；L1 判定以"扣成本后是否真赚钱"为准。

### 4.6 L1 计算口径（冻结时写死，不得运行后修改）

| 项 | 定义 |
|---|---|
| 样本单元 | EP-01 冻结口径下每个 episode 的**第一次** B 类观测 `i0 = obs[0]`；要求同 episode 内非 B 且 R60 完整的候选周 ≥5（`ENTRY_MIN_B0`）。与 `entry_phase.py::build_paired` 完全一致 |
| 本金归一 | 每笔名义本金 `N = 50,000 元`（与 L2 单笔基准同规模）；净收益率 = 净盈亏 / N。最低佣金 5 元/边按该名义本金计算 |
| 入场 | 信号周结束后第一个有效 bar 开盘价，`+` 滑点；超过 10 个市场交易日无有效 bar 记 `entry_fail`，不进入收益统计 |
| 退出 | 入场 bar 为第 1 个有效 bar，第 60 个有效 bar 收盘价，`−` 滑点。即 `exit_di = entry_di + 59` |
| 数据截止 | `exit_di ≥ 股票最后 bar 数` → `open_at_data_end`，按最后收盘价估值但**不计入已实现收益**，单列 |
| 毛收益 | `raw_exit / raw_entry − 1`（等价于 `qfq_exit / qfq_entry − 1`），不含任何费用与滑点 |
| 成本 | 买入：`股数=N/raw_entry`，`买入金额=股数×raw_entry×(1+滑点率)`，佣金 `max(金额×佣金率, 5元)`；卖出：`卖出金额=股数×raw_exit×(1−滑点率)`，佣金 `max(金额×佣金率,5元)`，印花税 `金额×法定税率(仅卖出)`，过户费按 §4.3 分段 |
| 成本基数 | 一律用**原始价**换算的成交金额；沪市面额口径过户费用 `股数×1元×费率`（2012-05-31 及之前，最低 1 元/边） |
| 年度归属 | 按**退出（实现）日期**所属自然年；2005–2025 共 21 个完整年，零交易年计 0；2026 YTD 单列 |
| NAV / MDD | `NAV_t = 1 + Σ(前 t 笔净收益率)`，按退出日升序（同日按代码）排列；`MDD_L1 = max(1 − NAV_t / max_{s≤t} NAV_s)`。另报单仓复利曲线 `Π(1+r)` 的 MDD 仅作参考，不参与判定 |
| 连续亏损 | 按同一退出日顺序，净收益率 ≤0 的最长连续笔数 |
| Bootstrap | 以 episode（= 本样本中一笔交易）为重采样单位，1000 次，`numpy.random.default_rng(20261107)`，取均值 2.5%/97.5% 分位 |
| 剔除前 1% | 删除净收益率最大的 `ceil(n×1%)` 笔后重算均值 |
| qfq 实现 | 使用 `cache/raw`（新浪不复权全量）+ `cache/factors`（新浪累计因子）在内存合成 `qfq = raw/f`，与 `cache/qfq` 文件等价；不使用 `cache/stocks` |
| 成本情景 | 基准 0.030%/边 + 10bp；保守 0.100%/边 + 20bp；压力 0.300%/边 + 30bp，且 2012-06-01–2015-07-31 沪市过户费再 ×2（覆盖券商留存部分） |

## 5. 第二层 L2：实际可交易性（L1 通过后才启动）

### 5.1 涨跌停价

```
P_limit_up   = round_tick(P_ref × (1 + r))
P_limit_down = round_tick(P_ref × (1 − r))
```

- `P_ref` = **除权参考价**（不复权口径）；无除权事件时为前一有效 bar 收盘价。
- `round_tick`：0.01 元，四舍五入。
- `r` 由 `HISTORICAL_MARKET_RULES.csv` × `HISTORICAL_SECURITY_STATUS.csv` 联合取值。
- `ref_stale`（前 bar 间隔 >5 个市场交易日）、`limit_rule_mismatch`（与当日 high/low 冲突）、`special_regime_unknown` 的日期**一律不判涨跌停**，并单列占比。

### 5.2 成交代理

- 买入：开盘价；**开盘涨停 / 一字涨停（含 volume>0）一律不可买**，顺延；开盘跌停可买。
- 卖出：第 61 个有效 bar 起开盘价；**开盘跌停 / 一字跌停一律不可卖**，顺延。
- 退出**不设强制期限**；数据截止仍未成交 → `open_at_data_end`；永远无法卖出 → `exit_impossible`。
- 所有成交均为日线代理，报告须附 `EXECUTION_ASSUMPTIONS.md` §11 声明。

### 5.3 ST_UNKNOWN 双口径

| 口径 | 处理 | 用途 |
|---|---|---|
| 主口径（保守） | `ST_UNKNOWN` 一律按 **5%** 涨跌幅判定 | L2 主结果 |
| 敏感性口径 | `ST_UNKNOWN` 一律按 **10%** 判定（普通股票规则） | 对照 |
| 统计要求 | 两口径分别输出成交率、退出延迟率、净收益、净期望 | 必须分开表 |

- 官方声明：**"这不是历史 ST 状态还原，而是保守代理 + 敏感性对照。"**
- 禁止把 `ST_UNKNOWN` 样本删除后把剩余结果称为"全池结果"。
- 必须披露 `ST_UNKNOWN` 占全部信号的比例；若 >10%，结论只能表述为"在可判定子样本上成立"。

### 5.4 容量（三档）

- 单笔买入金额上限 = 信号日之前 20 个有效交易日均成交额 × `CAP`。
- `CAP ∈ {0.25%, 0.5%, 1%}`，三档全部披露；0.5% 为基准。
- 20 日窗口内有效 bar <15 → `adv_insufficient`，不参与主判定。
- 全部标记 `ADV_APPROX`；不得使用买入日当天成交额。

### 5.5 组合与资金占用

- 初始本金 1,000,000 元/账本；最大同时持仓 20 笔；单笔 = 买入时组合最新净资产的 5%。
- 同日多信号排序：`SHA256(seed | 候选周结束日 | 股票代码)`，`seed = 20261107`。
- 无杠杆、不加仓、不调仓、现金零利息。
- 日频收盘盯市；停牌按最后可得收盘价。

### 5.6 L2 验收

| 编号 | 条件 |
|---|---|
| L2-1 | 入场失败率 ≤ 5% |
| L2-2 | 退出延迟率 ≤ 10% |
| L2-3 | 期末未平仓率 ≤ 0.5%，且 `exit_impossible` 单列 ≤ 0.5% |
| L2-4 | 组合日频 MDD ≤ 30% |
| L2-5 | `C_stock ≤ 20%`、`C_year ≤ 50%` |
| L2-6 | 0.25% / 0.5% / 1% 三档容量下净期望同号 |
| L2-7 | ST 5% 与 10% 两口径净期望同号 |

失败（任一）：净期望 ≤ 0 或 CI 含 0；MDD > 40%；`C_stock > 30%`；`C_year > 60%`；三档容量下净期望变号。

## 7. 复权数据方案与覆盖率验证

优先级：

1. **全池历史复权因子**（首选）：新浪 `qfq.js` 累计因子端点，`qfq = raw / f`。
