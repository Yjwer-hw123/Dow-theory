# EP-02e 可投资性诊断协议（冻结前）

- 阶段：EP-02e
- 目的：查明 B 类信号的收益能否通过合理的组合风险架构被保留下来
- 状态：诊断，不是策略开发；不产生采用/拒绝结论，只产出证据
- 冻结对照：B0（不止损、60 bar 收盘卖、3 仓、每笔 1/3 NAV、同日先到先得）
- 数据来源：`out/entry_phase_03/p3_features.csv`、`out/entry_phase_02/p2d_trades.csv`、`p2d_main_nav_B0.csv`、`l2_daily_nav.csv`、`attr_market_proxy.csv`、`cache/qfq/*.parquet`

## 1. 只研究三个问题

| 编号 | 问题 | 必须回答 |
|---|---|---|
| Q1 | 回撤从哪里来 | 哪些年份、市场环境、持仓重叠与个股亏损共同构成 75% 回撤 |
| Q2 | 收益如何被捕获 | 从 11,419 个信号到实际成交，机会在哪些环节损失 |
| Q3 | 组合有没有改善空间 | 3 仓约束下收益是否过度集中、仓位是否长期被低质量机会占用 |

不新增交易规则，不做参数搜索，不生成新的策略配置回测。

## 2. 口径定义（运行前固定）

**Q1 回撤来源**
- 回撤事件：NAV 自历史高点回撤首次达到 ≥10%，记为事件开始；事件内最低点为谷底；NAV 重回前高为结束；未恢复记至数据末端。
- 对每个事件报告：深度、峰值/谷底/恢复日期、交易日数、水下天数、区间市场代理收益。
- 对最大事件做分解：NAV 变动 = 窗口内已实现盈亏（按卖出日）+ 未实现变动（残差）；列出贡献最大的亏损交易、入场年份分布、同时持仓数分布与满仓天数占比。
- 同时报告全部 ≥10% 回撤事件，避免只挑一个窗口。

**Q2 收益捕获**
- 漏斗：全部信号 → 当日可竞争信号 → 成交 / 跳过，跳过原因分三类：`max_positions`（满仓）、`cash_insufficient`（现金不足）、`duplicate`（同标的已持仓）。
- 容量上限：`slots × 交易日数 / 60`（3 仓、固定 60 bar 持有）；利用率 = 实际成交 / 上限。
- 选择偏差：成交组 vs 跳过组的单笔净期望、总净收益（统一 50,000 元名义）；同日匹配差分（仅统计同日候选 ≥2 的日期）。
- 入场时滞：`signal_date → entry_date` 的交易日间隔分布。

**Q3 组合改善空间**
- 集中度：已实现盈亏 top1/5/10/20 笔占比、HHI、前 5 只股票占比、最大单年占比。
- 占用质量：持仓日中由「最终净收益为负」的交易所占比例；满仓/半仓/闲置天数占比；入场年份 cohort 的成交数、净期望、占用天数。
- 资本效率：CAGR、MDD、CAGR/MDD；仅并列引用已冻结的 20 仓对照结果，不新跑配置。

## 3. 强制报告规则

1. 任何与风险相关的数字，必须同时列出对应的收益代价与机会成本，禁止单指标结论。
2. 「回撤下降」本身不构成策略改善证据。
3. 不使用盘中触价口径。
4. 不把 3 仓路径依赖下的期末净值解释为策略优劣。
5. 不重复 EP-02c 的持仓期解剖与 EP-02d 的止损回测。

## 4. 明确禁止

- 不修改 B 类信号定义。
- 不新增市场过滤器。
- 不研究新的止损阈值。
- 不研究止盈。
- 不调整参数追求更漂亮的回测。
- 不因诊断结果临时改变本协议口径。
