# EP-02f 提前释放仓位的收益来源归因（任务书）

- 版本：1.0（冻结）
- 日期：2026-11-08
- 性质：**诊断归因**。只回答「ATR×2 多赚的钱从哪里来」，不产生采用决定，不改动任何冻结基线。
- 上游：EP-02e 容量诊断（协议 SHA256 `61A87D33…`）；EP-02d 止损裁决 `REJECT_ALL`（冻结）。
- 本任务书 SHA256 由 `EP02F_ATTR_PROTOCOL_FREEZE.json` 记录，脚本运行前强制校验，校验失败拒绝运行。

## 0. 目的

ATR×2（ATR20 × 2.0 止损 + 2.5R 止盈）在同一区间内期末净值 763 万，高于冻结基准 B0 的 572 万，但单笔期望从 4.69% 降到 2.41%，成交从 201 笔增至 370 笔。需要判定：多出的收益来自

- **容量释放**：提前退出让有限的三仓更早承接后续信号，捕获了原本被满仓挤掉的机会；或
- **路径偶然**：3 仓路径依赖下的样本内参数扫描产物，换一条路径就不成立。

## 1. 研究对象（三者均按同一执行口径）

| 代号 | 出场规则 | 资金/仓位节律 | 用途 |
|---|---|---|---|
| P0 | 60 bar 收盘卖（B0） | B0 原始 | 冻结基准，必须精确复现 |
| P1 | ATR×2 止损 + 2.5R 止盈 | 实际释放 | 待归因对象，必须精确复现 |
| P2 | ATR×2 止损 + 2.5R 止盈 | **冻结为 B0 的 60 bar 回款日** | 诊断反事实，不可投资 |

P2 定义：每笔交易仍按 P1 的规则提前卖出，但卖出所得计入**受限现金**，直到该笔交易在 B0 口径下的 60 bar 出场日次日才解冻；期间不得用于建仓。NAV 计入受限现金。P2 用来把「出场规则」与「提前拿回资金」两件事拆开。

统一口径（与 EP-02d 主口径一致）：收盘确认、次日开盘成交、开盘封跌停顺延、保留 60 bar 上限、base 成本、100 万初始、3 仓、每笔 1/3 NAV、同日按 (signal_date, code) 先到先得、回款次日可用。

## 2. 四个问题与指标定义

**信号身份** = `(signal_date, code)`。同一信号在两个组合中最多成交一次，可唯一对应。

### Q1 提前退出释放了什么

- `成交集合`：P0、P1 各自实际成交的信号身份集合。
- `新增成交` = P1 \ P0；`被挤出` = P0 \ P1；`共同成交` = P0 ∩ P1。
- 对每笔新增成交，回溯其在 P0 同日的竞争结果，分类为：`max_positions`（满仓）、`cash_insufficient`（现金不足）、`duplicate`（同码已持）、`not_attempted`（P0 未进入撮合，如数据不足）。
- 报告：新增/挤出笔数、分类构成、逐年分布、新增成交发生时 P0 的持仓占用（0/1/2/3）。

### Q2 提前退出损失了什么

- `提前退出交易` = 共同成交中 P1 出场日早于 P0 出场日者。
- `续持反事实净收益 net60` = 同一信号在 B0 口径下 60 bar 的净收益（同一入场价、同一成本口径）。
- `提前退出损益` = `(net60 − net_p1) × notional`。正值表示提前卖出少赚，负值表示提前卖出避损。
- 按出场原因（stop / tp）分别汇总，并统计 net60 高于实际退出价的天数占比。

### Q3 新成交是否值得

- `新增净利` = Σ 新增成交 pnl。
- `资金日收益率` = pnl / (notional × hold_bars)，分别计算新增成交与 P0 全部成交。
- 新增成交中亏损笔数、亏损金额合计、盈利集中度（top1 / top2 占新增净利比例）。
- 报告剔除 2006 年 cohort、剔除新增净利前 2 笔后的剩余净利。

### Q4 容量收益是否真实

- `总差 Δtotal` = NAV(P1) − NAV(P0)
- `出场效应 Δexit` = NAV(P2) − NAV(P0)
- `容量效应 Δcap` = NAV(P1) − NAV(P2)
- 恒等式：Δtotal = Δexit + Δcap（按构造精确成立）。
- `容量占比` = Δcap / Δtotal（Δtotal > 0 时）。

## 3. 判定规则（预注册）

| 编号 | 条件 |
|---|---|
| G1 | Δtotal > 0 且 容量占比 ≥ 60% |
| G2 | 新增净利 > 0 且 新增资金日收益率 ≥ P0 全部成交资金日收益率 |
| G3 | 剔除 2006 年新增成交后新增净利 > 0；剔除新增净利前 2 笔后仍 > 0；且容量占比 ≥ 50% |
| G4 | 仅报告：提前退出损益的 stop / tp 拆分，不参与判定 |

结论分类：

- `CAPACITY_REAL_SIGNAL`：G1、G2、G3 同时成立。
- `MIXED`：Δtotal > 0 且 G1 成立，但 G2 或 G3 不成立。
- `PATH_LUCK_SUSPECT`：Δtotal ≤ 0，或容量占比 < 60%，或新增净利 ≤ 0。

分类只描述证据结构，**不构成采用建议**。

## 6. 复现校验（硬性门槛）

- P0 期末 NAV 必须等于 `5,719,552.238656651`，相对偏差 ≤ 1e-9，成交 201 笔。
- P1 期末 NAV 必须等于 `7,629,540.673526994`，相对偏差 ≤ 1e-9，成交 370 笔。
- 任一不满足，脚本终止，不输出结论。

## 7. 已知局限（必须写入报告）

- 同一样本内的参数选择，ATR×2 本身即样本内最优，归因不能消除选择偏差。
- P2 的受限现金金额取决于 P1 的实际卖价，与 B0 的 60 bar 卖价不完全相同，因此 Δexit 与 Δcap 是「路径近似拆分」，不是严格的同一现金流对照。
- 3 仓路径依赖：新增成交与被挤出成交不是同一批交易，笔数差额不等于净额。
- 收盘确认、次日开盘成交：止损与止盈的真实盘中效果可能不同。
- 沪指对照不参与本任务判定。
