## 0. 研究问题

EP-02g 显示：15 日的超额主要出现在指数走平的期间，牛市跑输指数，熊市仍 -31%/年。但这不等于「策略靠震荡市赚钱」，因为归因可能来自三种完全不同的原因。本阶段要区分它们：

| 编号 | 解释 | 若成立意味着什么 |
|---|---|---|
| E1 | 策略确实更擅长「大盘无方向、但个股存在局部趋势」的环境 | 下一步应研究个股结构与入场质量 |
| E2 | 历史上只有少数年份贡献了大部分收益 | 任何新增技术指标都可能只是过拟合 |
| E3 | 02g 的市场状态划分方式本身造成了归因偏差 | 应先修定义，再谈策略方向 |

**不是**重做牛熊识别：本阶段的主变量是「趋势强度（方向性）」，方向（涨/跌）只作为辅助分层。

## 1. 对象与口径

- 信号池：冻结的 11,419 个 B 类信号，要求入场后至少 60 根 bar 可用（与 EP-02g 完全同一池，保证可比）。
- 观察期限：**固定 H=15 个交易日**，不含任何止损、止盈、移动止损。不比较其他期限。
- 收益口径：`net15 = qfq 空间收益 − raw 空间成本`，成本复用 `entry_phase_02_l1.eval_trade(..., "base")`（0.030%/边 + 10bp 滑点、佣金最低 5 元、过户费与印花税分段）。
- 执行口径：收盘确认、次日开盘成交（与 EP-02d 主口径一致）。
- 组合级（仅一致性核对）：100 万、3 仓、每笔 1/3 NAV、同日 (signal_date, code) 先到先得、回款次日可用、base 成本。
- 复现门槛：组合级 H=15 必须等于 EP-02g 结果 `22,335,139.61910044`、672 笔，相对偏差 ≤ 1e-9；否则终止。

## 2. 环境定义（事前、因果、无时点穿越）

### 2.0 时点口径（冻结）

| 时点 | 已发生的事实 | 允许使用 |
|---|---|---|
| `signal_date` 收盘 | 当日收盘价已确定；B 类信号在此刻产生；环境标签在此刻确定 | 指数与个股截至 `signal_date` 收盘（含）的全部数据 |
| `entry_date` 开盘 | 实际买入发生 | **只用于成交与损益，不得用于任何环境或结构分类** |
| `entry_date` 收盘 | 买入之后才产生 | **禁止用于分类** |
| 第 1–15 根持仓 bar | 观察窗口 | 用于 net15 / MAE / MFE / 恢复，不回流到分类 |

- 关键约束：**环境标签必须在买入之前已经可知**。使用 `entry_date` 收盘价即构成时点穿越，虽未触及未来，但已使用了买入后才产生的信息，故明确禁止。
- 指数序列：`cache/000001_daily.parquet` 收盘价，按交易日历对齐。
- 交易日映射：标签取 `signal_date` 当日在交易日历上的位置；若 `signal_date` 不在日历中，取 ≤ `signal_date` 的最后一个交易日，并计数报告（该计数应为 0，非 0 需列示）。

### 2.1 主定义：趋势强度 + 方向（三态 + 两个边界态）

对每个交易日 t，只用 `close[t]` 及更早数据：

- 路径效率比 `ER_N[t] = |close[t] − close[t−N]| / Σ_{i=t−N+1..t} |close[i] − close[i−1]|`，理论取值 [0,1]。
- 方向 `d60[t] = close[t] / close[t−60] − 1`。
- 实际取值取 `t = signal_date`，**不是** `entry_date`。

| 状态 | 条件 | 处理 |
|---|---|---|
| 上升趋势 `up` | `ER60 ≥ 0.30` 且 `d60 > 0` | 并入 `trend` |
| 下降趋势 `down` | `ER60 ≥ 0.30` 且 `d60 < 0` | 并入 `trend` |
| 震荡 `range` | `ER60 < 0.30` | 独立一类 |
| `neutral` | `ER60 ≥ 0.30` 且 `d60 == 0`（浮点差 ≤ 1e-12 视为 0） | 单独统计，不并入上述三类 |
| `unknown` | `signal_date` 之前不足 60 根 bar | 剔除并计数 |

- `neutral` 不得静默归入 `up`、`down` 或 `range`：必须出现在 `p2h_boundary_counts.csv` 与报告中，列出笔数、单笔均值、胜率；不参与 T1–T4 的差分计算。若 `neutral` 占比超过 5%，报告追加标记 `NEUTRAL_HIGH`（仅注解，不改变闸门）。
- 分母 `Σ|Δclose| = 0`（窗口内价格完全不动）：**定义 ER = 0**，归入 `range`，并单独计数报告（列名 `er_zero_denom`）。理由：无路径位移即无方向，不应丢弃样本。
- 阈值 0.30 为**事前固定**，不得根据结果调整；含义为「60 日净位移不足总路径的 30% 视为无持续方向」。

### 2.2 敏感性定义（只报告，用于 E3 判定；同样以 `signal_date` 收盘取值）

| 代号 | 定义 | 边界处理 |
|---|---|---|
| S-a | `ER20 ≥ 0.35` 为趋势，`d20` 符号定方向 | `d20 == 0` → `neutral`；分母 0 → ER=0 → `range` |
| S-b | `ER120 ≥ 0.25` 为趋势，`d120` 符号定方向 | 同上规则 |
| S-c | EP-02g 方向口径：`r120 = close[t]/close[t−120] − 1`，`≥ +10%` 牛、`≤ −10%` 熊、其余震荡（t = `signal_date`） | 无 `neutral`；窗口不足 120 bar → `unknown` |

S-c 只用于检验「02g 的归因是否由定义方式造成」，不参与主结论。

### 2.3 个股结构（用于解释 E1，非环境定义）

在 `signal_date` 收盘（入场前）计算该股自身：

- `stock_ER20`：同法 20 日路径效率比（分母 0 时记 0）；
- `ma20_pos`：`close / MA20 − 1`（`signal_date` 收盘相对 20 日均线；不足 20 根 bar 记 `NaN` 并计数）。

分组：在每个环境内，按 `stock_ER20` 分为高/中/低三组（按环境分别取三分位），比较组间 `net15`。

### 2.4 边界计数

所有 `neutral` / `unknown` / `er_zero_denom` / `ma20_pos` 缺失 / 非交易日映射的样本数量必须写入 `p2h_boundary_counts.csv`，并在报告中列表；任何一类不得在运行时静默丢弃。

## 3. 指标

### 3.1 信号级（11,419 个信号，等权；主判定层）

按环境分别统计：

- 单笔净收益均值 `mean(net15)` 与中位数；
- 胜率（`net15 > 0` 占比）；
- 盈亏比 = `mean(盈利额) / |mean(亏损额)|`；
- `MAE15`：持有 15 根 bar 内最低收盘相对入场的最小值；`MFE15`：最大值（均用 close，与 EP-02g 一致）；
- 回撤恢复：15 根 bar 内首次收盘回到入场价（qfq 空间 `close ≥ entry`）的 bar 序号；未恢复记为 15。报告恢复比例与恢复天数中位数；
- 单笔日均 = `net15 / 15`。

### 3.2 组合级（3 仓、H15；仅一致性核对层）

- 按入场环境汇总成交笔数、净利、单笔均值、胜率；
- 按环境分解日度 NAV 对数收益，给出贡献占比与期间年化（与 EP-02g 同法）。

组合级存在 NAV 路径放大与成交集合差异，**不用于 T1–T6 判定**，只用于核对信号级结论是否被容量效应反转。

### 3.3 统计推断（按时间聚类，固定随机种子）

- 差分定义：`Δ = mean(net15 | range) − mean(net15 | trend)`，`trend = up ∪ down`；另分别报告 `range − up`、`range − down`。
- **样本与月份集合**：
  - 主定义固定使用完整 11,419 个信号，月份集合 `M_main` = 这些信号的入场月份全集，`m0 = |M_main|`；**不因 S-a / S-b / S-c 缺历史数据而缩减**。
  - S-a / S-b / S-c 各自使用**自身有效信号**（在该定义下标签不为 `unknown` 的信号）；其有效月份集合记为 `M_d`，`m_d = |M_d|`；分别报告 `unknown` 数量、有效信号数、有效月份数。
- **共同随机数**：预先生成 `U ∈ [0,1)^{10,000 × m0}`（`numpy.random.default_rng(20261108)`，一次生成），主定义与三个敏感性定义**共用同一组 U**。
- **每次迭代 r**：对定义 d，取 `U_r` 的前 `m_d` 个元素，索引 `floor(U_r[j] × m_d)`，从 `M_d` **有放回**抽取 `m_d` 个月；同月内全部信号整体进出，不重算标签。
- **有效迭代**：`range` 与 `trend` 两组均有样本才算该定义本次有效；各定义分别统计。
  - 主定义有效次数 < 9,500 → 整阶段判 `INSUFFICIENT_SAMPLE`。
  - 敏感性定义有效次数 < 9,500，或该定义下 `range` / `trend` 未达 T0（各 ≥1,000 笔、≥40 个月），则该定义**不具备 T1 资格**（既不计同号，也不计反号，报告标注 `SENS_INELIGIBLE`）。
- 迭代次数 10,000；主检验种子 `20261108`；T6 使用独立种子 `20261109`（见 3.4）。
- 区间取 5%–95% 分位（90% CI）。
- 对照：逐笔 iid 重采样使用同一 `U` 的前 N 个元素映射到 `0..N−1`，仅展示聚类修正幅度，不作判定依据。
- **命名与边界**：该方法只能称为「月度聚类 Bootstrap（month-cluster bootstrap）」。它保留**同一自然月内**信号之间的相关性，**不保留相邻月份之间的连续时间相关性**；报告不得将其表述为已充分处理时间序列相关。

### 3.4 T6 的差分口径（固定）

- 差分对象：`Δ_T6 = mean(net15 | high) − mean(net15 | low)`，high / low 为 `range` 环境内 `stock_ER20` 的高组与低组（三分位，中组不参与差分）。
- 月份集合：`M_range` = `range` 环境中**至少有一个有效信号**的入场月份；只从 `M_range` 抽样，`m_r = |M_range|`。
- 每次迭代：以种子 `20261109` 预生成 `U6 ∈ [0,1)^{10,000 × m_r}`，索引 `floor(U6[r][j] × m_r)`，从 `M_range` 有放回抽取 `m_r` 个月；保留被抽中月份内的**全部** `range` 信号及其原有高/低组归属。
- 分组阈值（三分位切点）在**原始** `range` 样本上一次确定，Bootstrap 过程中**不重新计算**分位数。
- 有效迭代 = 高组与低组均有样本；有效次数 < 9,500 时标记 `INSUFFICIENT_SAMPLE`。
- 必须报告：高组信号数与月份数、低组信号数与月份数、有效迭代次数、`Δ_T6` 点估计与 90% CI。

## 4. 预先固定的判定规则

| 编号 | 条件 | 对应解释 |
|---|---|---|
| T0 | 主定义：`range` 与合并后的 `trend`（`up ∪ down`）**各自**信号数 ≥ 1,000 且各覆盖 ≥ 40 个不同月份，`up` / `down` 仅作方向性报告、不参与本门槛；敏感性定义按 3.3 各自检查同一门槛 | 样本充足性 |
| T1 | 主定义 `Δ` **必须非零**（`|Δ| ≤ 1e-6` 视为零），且 S-a / S-b / S-c 中**至少两个**与其同号；只有样本与 Bootstrap 均达标（见 3.3）的敏感性定义才计入，`SENS_INELIGIBLE` 者既不计同号也不计反号；各定义 `|Δ| ≤ 1e-6` 均视为零 | 排除 E3 |
| T2 | 主定义 `Δ > 0`，且月度聚类 90% CI 下界 > 0；同时 `range` 胜率 > `trend` 胜率 | 支持 E1 |
| T3 | 风险不劣化：`range` 的 `|MAE15|` 均值不大于 `trend`，且盈亏比不低于 `trend` | 支持 E1 |
| T4 | 见下方 4.1 分项规则；通过需同时满足 a–d | 排除 E2 |
| T5 | `range` 入场至少覆盖 6 个不同自然年度 | 排除单周期偶然 |
| T6 | 仅在 `range` 环境内：`Δ_T6 = mean(net15 | high) − mean(net15 | low) > 0`，且 90% CI 下界 > 0；差分、月份集合、固定分组阈值与报告项按 3.4 执行 | E1 的机制证据 |

### 4.1 T4 的分项与结果分类

设 `range` 全部信号净利合计为 `P_range`，年份级净利为 `P_y`。

**不适格检查**，命中任一即 `NOT_APPLICABLE`（不计算占比）：

- `P_range ≤ 0`；
- 净利为正的年份数 < 3。

**通过需同时满足**：

- a. 前 3 大年份净利之和 `P_top3 > 0`；
- b. `P_top3 / P_range ≤ 60%`；
- c. 从信号样本中**删除净利最大年份的全部信号**后，`Δ` 仍 > 0（不得只从年度汇总表删行）；
- d. 在上述删除后的信号样本上重算月度聚类 Bootstrap：月份集合取剩余仍含信号的月份 `M′`，有放回抽取 `|M′|` 个月，10,000 次，种子 `20261108`，`Δ` 的 90% CI 下界 > 0。若有效迭代 < 9,500，整阶段判 `INSUFFICIENT_SAMPLE`。

**结果分类**：

| T4 结果 | 含义 | 对结论的作用 |
|---|---|---|
| `PASS` | a–d 全部满足 | 年份集中度未构成明显问题 |
| `FAIL` | 不适格检查通过，但 a–d 中任一不满足 | 年份集中度检验未通过，支持 E2 |
| `NOT_APPLICABLE` | 命中不适格检查（`P_range ≤ 0` → 原因码 `P_NEG`；正净利年份 < 3 → `FEW_POS_YEARS`） | 无法进行有意义的集中度检验；**不得解释为年份集中** |

`NOT_APPLICABLE` 既不视为 `FAIL`，也不视为通过：它使 `RANGE_EDGE_REAL` / `RANGE_LOCAL_TREND` 不能成立，并单独给出标签 `CONCENTRATION_NOT_TESTABLE`。

### 4.2 结论标签

| 标签 | 条件 |
|---|---|
| `RANGE_EDGE_REAL` | T0–T3、T5 通过，且 T4 = `PASS` |
| `RANGE_LOCAL_TREND` | 上述全部通过，且 T6 通过（更强版本） |
| `TREND_EDGE_REAL` | `Δ` 反向且对称闸门（T1–T3、T5 反向）通过，T4 = `PASS` |
| `YEAR_CONCENTRATION` | T4 = `FAIL`（E2） |
| `CONCENTRATION_NOT_TESTABLE` | T4 = `NOT_APPLICABLE`（无法检验；不构成 E2 证据，也不构成通过） |

## 7. 已知局限

- 环境标签存在滞后：效率比与方向都用已实现路径，转折附近归类不稳定。
- 指数环境 ≠ 个股环境；本阶段同时报告个股结构，但不能完全替代行业与风格分层。
- 信号在时间上高度聚集；月度聚类 Bootstrap 只保留同月相关性，不保留跨月连续相关性，也无法消除同一行情段的重复暴露。
- 15 日是 EP-02g 的样本内候选，本阶段沿用它是为了固定变量，不代表该期限已被验证。
- 组合级归因受 NAV 路径放大影响，故只作核对。
- 10bp 滑点不含市场冲击；任何放大仓位的结论都需要单独的压力测试。
- 全部结论来自同一样本，不构成样本外证据。
