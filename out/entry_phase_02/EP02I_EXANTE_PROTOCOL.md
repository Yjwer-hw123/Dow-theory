## 1. 要回答的问题

主问题（唯一）：

> 在每个月末，仅使用当时已经收盘的数据构造一个趋势倾向分数 `S`，能否在随后一个月的 B 类信号上，显著提高「`trend` 相对 `range` 的单笔优势」？

三个问题必须分开：

| 问题 | 状态 |
|---|---|
| 优势真实性：趋势环境是否确实优于震荡环境？ | EP-02h 已答：是（Δ = −3.89%，CI [−7.33%, −0.84%]） |
| 优势稳定性：优势是否跨年份普遍兑现？ | EP-02h 已答：否（T4:b，前 3 大优势年占净优势 80.1%） |
| 优势可识别性：优势大小能否被事前信息预测？ | **本阶段** |

本阶段回答的是**条件单笔优势的排序能力**，不是「未来某个月的组合收益会改善」。两者不得互相替代。

反问题：若主检验不成立，则 `YEAR_CONCENTRATION` **不得**被解释为可利用的择时机会。

**研究能力边界原则**：若最终判定为 `INSUFFICIENT_SAMPLE`，本阶段即以该结论结案；不得通过修改统计方法、合并样本、降低门槛或更换标准误，去追求一个「可识别」的结果。

## 3. 信息集与分数 S

**时点规则（最重要）**：`S` 一律在「`signal_date` 所属自然月的上一个自然月的最后一个交易日」收盘计算。同一自然月内所有信号共享同一个 `S`。禁止使用 `signal_date` 当日或之后数据，禁止使用 `entry_date` 任何数据。

**候选分数（事前列全，执行时不得增补）**：

| 代号 | 定义 | 来源 |
|---|---|---|
| `S1`（主） | 指数 `ER60` | `cache/000001_daily.parquet` |
| `S2` | 指数 `d60 = close[t]/close[t−60] − 1` | 同上 |
| `S3` | 指数 `close/MA200 − 1` | 同上 |
| `S4` | 市场宽度：池内收盘价 > MA60 的股票占比 | `cache/qfq` |
| `S5` | 复合：`z(ER60) + z(MA200pos)`，等权 | `S1` + `S3` |

- `z(·)` 使用**扩展窗口**标准化（起点 2005-01-01，仅用当日及之前数据，均值与标准差均滚动计算），禁止全样本标准化。
- 月末最后一个交易日若停牌/缺失，向前取最近有效交易日；连续缺失超过 5 个交易日则该月标记 `unknown` 并剔除该月全部信号。
- 所有分数使用原始连续值，**不预先分组、不设阈值**；分位数只用于报告经济幅度。
- 主检验只用 `S1`。`S2–S5` 为预注册敏感性，只报告、只做同号核对，不单独决定结论。

## 4. 模型

### 4.1 主模型 M1（判定用）

对信号级样本估计：

```
net15_i = α + β1·trend_i + β2·S_i + β3·(trend_i × S_i) + ε_i
```

- OLS；**月份聚类**稳健标准误（按 `signal_date` 的年月聚类）。
- 主检验：`β3 > 0`（`S` 越高，`trend` 相对 `range` 的单笔优势越大）。
- `β1` 仅作复现核对：不含 `S` 的原始均值差应等于 02h 的 `trend − range = +3.89%`（全样本），分折方向须一致。
- 不加入其他控制变量，不加入二次项/阈值项，不做变量选择。
- 稳健性（只报告，不参与判定）：`net15` 做 1%/99% winsorize；`trend` 只用 `up`；`S` 改用信号日前一交易日取值。

### 4.2 必要稳健性模型 M2（月份固定效应，判定用）

```
net15_{i,m} = α_m + β1·trend_i + β3·(trend_i × S_m) + ε_{i,m}
```

- `α_m` 为自然月固定效应，吸收该月所有共同冲击（包括整体市场收益）。
- `S_m` 是月份级变量，被 `α_m` 完全吸收，因此 **`β2` 在 M2 中不可识别**，报告中标注 `n/a`，不得解释。
- 识别来源：`β1` 与 `β3` 只由**同时含 `trend` 与 `range` 信号**的月份识别；仅含一类信号的月份只贡献 `α_m`，不贡献 `β1/β3`。
- 因此必须报告每折「同月同时含两类信号」的月份数 `n_both`，以及这些月份的 `trend`/`range` 笔数分布。`n_both` 是 M2 的识别基础，不是样本量的替代。
- M2 与 M1 使用同一批信号、同一 `net15`、同一 `S`，只多一组月份虚拟变量。
- **M2 是必要稳健性检验**：结果不因 M2 是否通过而事后增删；判定规则见 P2。

### 4.3 识别质量诊断（只报告，不设门槛）

M2 的 `β3` 只由双类月份识别。除 `n_both` 外，还必须报告识别结构；以下指标**只用于界定结论的可靠边界，不新增 PASS 门槛，不得据此剔除月份、改模型或改门槛**：

1. **年份分布**：逐年 `n_both`、`n_trend`、`n_range`，并标出双类月份为 0 的年份。
2. **`S1` 分布**：双类月份的 `S1` 的 min/p10/p25/p50/p75/p90/max、不同取值数与极差；train 的 p10–p90 区间覆盖的双类月份数。
3. **逐月影响度**：分别在 M1 与 M2 上做留一月（leave-one-month-out）估计——删除某自然月全部信号后重估 `β3`；报告 `β3` 的分布、相对变化最大的 5 个月份及其 `n_both`。
4. **集中度标记**：若双类月份落在 ≤ 3 个自然年，在报告摘要与 `p2i_summary.json` 中标 `IDENTIFICATION_CONCENTRATED`，但**不改变判定标签**。

## 5. 推断与时间依赖

11,419 笔信号不等于 11,419 个独立观测：同一交易日可能有多个信号，同一自然月内信号相关，且 15 日持有期会让相邻月份的信号窗口部分重叠（最多约 10 个交易日）。

### 5.1 判定口径（唯一）

- 一切 `β3` 的通过/不通过，只以**月份聚类稳健标准误**的结果为准（M1 与 M2 各自）。
- 禁止在多种标准误之间挑选更显著的一个作为结论。

### 5.2 报告口径（不参与判定）

| 项 | 做法 |
|---|---|
| 交易日聚类 | 以 `signal_date` 为聚类单位重估 M1/M2，报告 `β3` 与 90% CI |
| Newey–West | 按 `entry_date` 排序，Bartlett 核，滞后 `L = 63` 个交易日（覆盖 15 日持有与月度重叠），报告 `β3` 与 90% CI |
| 月份 block bootstrap | 有放回抽月份（同月信号整体出入），10,000 次，seed `20261109`，90% 百分位 CI；有效次数 < 9,500 时报告 `INSUFFICIENT_BOOTSTRAP` |
| 同日聚合 | 对每个 `(signal_date, env)` 先取 `net15` 均值，再重估 M1/M2，报告 `β3` |
| 共同冲击 | 报告同日信号数的分布、占比最高的 10 个日期；若单日信号数 > 全样本 0.1%，额外报告剔除该日后的 `β3` |
| 相邻月相关性 | 计算月度代理 `Δ_m = mean(net15 | range, m) − mean(net15 | trend, m)` 的 lag1–lag3 自相关，仅报告 |

- 若上述任一口径与判定口径的 CI 结论相反，必须在报告中并列呈现，不得只保留有利的一项；结论仍按 5.1 判定，但标签后追加 `(INFERENCE_SENSITIVE)` 标记。

## 6. 切分（固定，不可交叉、不可因结果调整）

| 折 | 条件 | 用途 |
|---|---|---|
| train | `signal_date ≤ 2015-12-31` | 估计模型、确定 `S` 的尺度与 p10/p90 边界 |
| validate | `2016-01-01 ≤ signal_date ≤ 2020-12-31` | 检验方向与经济幅度，不修改特征与函数形式 |
| test | `signal_date ≥ 2021-01-01` | 只执行一次，最终样本外检验 |

- `S` 的标准化参数与 p10/p90 切点**只用 train 拟合**，其余折冻结使用。
- test 只跑一次。若发现实现错误需修正，必须整折重跑并记录原因；不得依据 test 结果改模型、改分数、改切分。
- **若 train 与 validate 通过、test 未通过，最终结论就是「未获得样本外支持」**，不得合并样本重估、不得换模型后重测来挽救。

## 7. 预注册闸门

| 编号 | 条件 |
|---|---|
| P0 样本 | train ≥ 4,000 笔且 ≥ 80 个月（`trend` ≥ 700、`range` ≥ 3,000）；validate ≥ 2,000 笔且 ≥ 40 个月；test ≥ 2,000 笔且 ≥ 40 个月；`S` 缺失剔除 ≤ 1%；**M2 识别月数：train `n_both` ≥ 20，validate ≥ 8，test ≥ 8**（不足即视为 M2 不可评估，整阶段 `INSUFFICIENT_SAMPLE`） |
| P1 复现 | train 中不含 `S` 的原始均值差 `trend − range > 0`，且与 02h 全样本方向一致 |
| P2 样本内可识别 | M1 与 M2 **同时**满足：train 与 validate 的 `β3 > 0`，且两折月份聚类 90% CI 下界均 > 0 |
| P3 经济幅度 | 切点取 train 的 `S1` 的 p10/p90；以 M1 的 `β3` 计算 `β3·(p90−p10) ≥ 1.0 个百分点/笔`（M2 同式报告、不单独判定）；validate 与 test 均报告月份聚类 90% CI，test 须与 validate 同向。**不得只报 `β3` 显著性** |
| P4 年份稳定 | 见 7.1 |
| P5 样本外确认 | test 中 M1 与 M2 的 `β3 > 0`，月份聚类 90% CI 上界 ≥ 0，且 `β3·(p90−p10)` 与 validate 同向 |

### 7.1 P4 的具体边界

**有效年份**（加权前先判定，防止小样本年份与大样本年份等权）：

- 当年 `trend` ≥ 30 笔且 `range` ≥ 300 笔；
- 当年有信号的月份数 ≥ 6；
- 当年 `S1`（月末值）的不同取值数 ≥ 6（确保年内存在 S 变化）。

**计算**：

- 在每个有效年份内单独估计 M1 的 `β3_y`（仅报告，不做等权投票）；
- 有效年份中 `β3_y > 0` 的比例 ≥ 70%；
- 留一年检验（仅在 train 的有效年份上）：对每个有效年份 `y`，删除该年全部信号后重估 M1 得 `β3,-y`，要求：
  - 所有 `β3,-y > 0`；
  - `|β3,-y − β3| / |β3| ≤ 50%`。
- **不可评估规则**：若 `|β3| < 0.002`（即 0.2 个百分点/单位 S），比例不稳定，P4 判为 `NOT_EVALUABLE`，按**未通过**处理；不得因此放宽 50% 或改用其他分母。
- 任一有效年份被删除后若有效年份数 < 5，P4 判 `NOT_EVALUABLE`，同样按未通过处理。

### 7.2 判定顺序与标签

| 标签 | 触发条件 | 含义 |
|---|---|---|
| `INSUFFICIENT_SAMPLE` | P0 未通过（含 `n_both` 不足、`S` 缺失超限） | **数据不足以识别**，不是假设被证伪 |
| `CI_FAIL` | P0 通过、P2 未通过 | 样本足够，但统计证据不足（符号不一致或 CI 含 0） |
| `ECONOMIC_FAIL` | P0、P2 通过，P3 未通过 | 统计关系可能存在，但经济幅度 < 1.0 个百分点/笔 |
| `STABILITY_FAIL` | P0–P3 通过，P4 未通过（含 `NOT_EVALUABLE`） | 关系存在，但跨年份不稳定或无法评估 |
| `NO_OUT_OF_SAMPLE_SUPPORT` | P0–P4 通过，P5 未通过 | 样本内成立，test 不支持 |
| `EX_ANTE_IDENTIFIABLE` | P0–P5 全部通过 | 条件优势可被事前信息排序 |

- 主标签按上表顺序取**第一个**失败项；其余失败项以 `(ALSO: CI_FAIL, …)` 追加，便于看到多重原因。
- 若 `P2` 只有 M2 未通过、M1 通过，追加 `(M2_FAIL)`；只有 M1 未通过则追加 `(M1_FAIL)`；两者都未通过不加后缀。
- `PARTIAL_IDENTIFIABILITY` 自 v0.3 起不再使用，由 `ECONOMIC_FAIL` / `STABILITY_FAIL` 取代。
- 允许后缀：`(INFERENCE_SENSITIVE)`、`(P4:NOT_EVALUABLE)`、`(IDENTIFICATION_CONCENTRATED)`。
- **禁止把以上任一失败标签统一表述为「趋势优势不存在」或「假设被证伪」**：它们分别对应数据不足、统计不足、经济不足、稳定性不足、样本外不足，是五种不同结论。

## 8. 实现一致性要求（脚本必须断言，失败即拒绝运行）

以下断言与协议 SHA256 校验同级；任一失败，脚本退出且不产出结果文件。

1. **同一样本**：M1 与 M2 使用完全相同的行集合与顺序。断言 `len(panel_m1) == len(panel_m2)` 且行索引一致；分折过滤不得因 `dropna` 差异而产生不同样本。
2. **同一月份键**：统一用 `signal_date.to_period("M")` 生成月份键；M2 固定效应、月份聚类、block bootstrap 的月份集合必须使用同一个键，不得改用 `entry_date` 或自然月文本。
3. **同一 `net15`**：M1、M2、P3、诊断表共用同一列，不得重复计算或四舍五入。
4. **P3 计算**：`p10/p90` 只用 train 的 `S1` 取值（不是全样本、不是信号级 `S`），切点须落盘；预测优势差为 `β3·(p90−p10)`，其 90% CI 由**同一个** `β3` 的 CI 端点乘以 `(p90−p10)` 得到；另报 block bootstrap 版本，两者不一致时标 `(INFERENCE_SENSITIVE)`。不得用 `β3` 的显著性替代经济幅度结论。
5. **M2 的 `β2`**：输出 `n/a`；不得把被 `α_m` 吸收的系数填 0 或强行估计。
6. **`n_both` 口径**：统计「同一月份同时存在 ≥1 笔 `trend` 且 ≥1 笔 `range`」的月份数，不是 `trend` 月数。
7. **逐月影响度**：留一月重估必须在 M1 与 M2 上分别执行，且与主结果使用同一月份键、同一样本过滤。

- 不做止盈止损、加仓、仓位、择时开关的回测。

- 不修改 EP-02h 的任何冻结文件、产物或脚本；不重跑 02h。

## 11. 与 EP-02h 的边界

| EP-02h | EP-02i |
|---|---|
| 趋势优势是否真实、是否跨年份稳定？ | 能否事前识别趋势相对优势？ |
| 结论：`YEAR_CONCENTRATION (T4:b)` | 结论：`EX_ANTE_IDENTIFIABLE` / `CI_FAIL` / `ECONOMIC_FAIL` / `STABILITY_FAIL` / `NO_OUT_OF_SAMPLE_SUPPORT` / `INSUFFICIENT_SAMPLE` |
| 描述历史优势的性质 | 检验事前预测能力 |

- 02h 的 `YEAR_CONCENTRATION (T4:b)` 保持不变，作为正式阶段结论。
- 本阶段不重新定义趋势/震荡，不改 `H=15`，不改样本池。
- 即使得到 `EX_ANTE_IDENTIFIABLE`，也不得回写为「02h 的优势稳定」；稳定性问题（T4:b）不因可识别性而消失。

## 12. 价值门槛与结果决策（预注册）

本阶段的产出不是一个待讨论的统计量，而是一个**去/留决策**。test 跑完即出决策，不设「再看看」的中间态。无论结果如何，阶段结束后不再围绕 `S` 或 `β3` 增加检验、改窗口、换标准误或延长样本。

| 结果标签 | 唯一决策 | 明令禁止 |
|---|---|---|
| `EX_ANTE_IDENTIFIABLE` | 进入 EP-02j 策略化验证（见 12.1） | 不得在 EP-02i 内继续调参、加检验 |
| `NO_OUT_OF_SAMPLE_SUPPORT` | 放弃当前事前识别方法，`S1–S5` 不再作为择时依据 | 不得合并样本、换标准误、重跑 test |
| `CI_FAIL` / `ECONOMIC_FAIL` / `STABILITY_FAIL` | 记录失败类型；该方法不成立，不围绕 `S` 迭代 | 不得换特征集重来而不新立阶段 |
| `INSUFFICIENT_SAMPLE` | 承认现有数据无法识别，不继续堆统计模型 | 不得为凑样本放宽门槛 |

**结论边界（失败方向同样适用）**：`CI_FAIL` 等只否定本阶段预注册的五个候选分数，**不证明「趋势优势原则上不可事前识别」**。若要换问题或换信息集，必须新立阶段并说明与 EP-02i 的差异；不得在同一 test 集上反复尝试。

### 12.1 成功后交给谁：EP-02j 的入口条件

`EX_ANTE_IDENTIFIABLE` 只说明排序能力，不等于可交易。进入 EP-02j 时必须：

1. 把 `S` 转成**事前可执行**的规则（阈值 / 优先级 / 仓位），阈值只能用 train 确定；
2. 成本口径：佣金、印花税、滑点、涨跌停不可成交，沿用现有 `base/cons/stress` 三档；
3. 报告样本外净值、CAGR、MDD、盈亏比、无趋势期的资金闲置与机会成本；
4. **EP-02j 不通过时，不回到 EP-02i 改模型**；两阶段各自独立结案。

## 13. 已知局限

- 样本跨度约 21 年，月度观测远少于 11,419 笔信号；月份聚类不吸收跨月重叠，故另列 Newey–West 与 block bootstrap。
- 指数分数刻画的是市场环境，不等于个股环境；`trend` 样本仅 1,177 笔，M2 的 `n_both` 可能偏低。
- 若双类月份集中于少数年份，M2 的交互效应本质上由这些年份识别；即使通过 P2，也只说明在该识别结构下成立，不能外推为长期稳定关系。
- 线性交互可能漏掉阈值/非线性效应；本阶段刻意不搜索函数形式。
- 优势若由少数年份驱动，交互项估计对这些年份敏感；P4 用于暴露而不是修正。
- 全部结论来自同一样本，不构成样本外证据；`EX_ANTE_IDENTIFIABLE` 不等于可交易。
