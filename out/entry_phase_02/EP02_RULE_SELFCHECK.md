## 2. 发现的口径风险（必须在实现时处理）

| 编号 | 风险 | 处理要求 |
|---|---|---|
| R1 | `SH_TR_4` / `SH_TR_5` 的「适用市场」写成「沪深A股」，而 `SZ_TR_1` / `SZ_TR_2` 也覆盖同一期间 | **实现必须按交易所分表**：沪代码只走 `SH_TR_*`，深代码只走 `SZ_TR_*`；**禁止把两张表相加**，否则 2015-08 起过户费翻倍 |
| R2 | 面额口径过户费需要股数，股数需要原始价 | 必须以 `raw_price = qfq_price × f` 换算，**不得用复权价计算股数**（会系统性低估或高估费用） |
| R3 | 压力情景「券商留存 ×2」容易被误扩展到全期 | 硬性限定 **2012-06-01 – 2015-07-31**，其余期间不得 ×2 |
| R4 | 经手费、证管费表的存在会被误当成成本项 | 代码中只能出现在「校验/断言」路径，不得进入 `total_cost` |
| R5 | 印花税 `STAMP_2008B` 单行跨越 2008-09-19 至 2023-08-27 | 合法（税率与方向在此段不变），但实现需按日期取行，不得按年份硬编码 |
| R6 | 深市 2015-07-31 及之前过户费为 0 的理由仅写在备注 | 必须在代码注释与报告脚注中重复写明「从经手费分成」，防止后人误补 |

## 3. 实现期断言（冻结后写代码时逐条验证）

- [ ] 印花税按交易日逐日命中唯一一行（无重叠）。
- [ ] 沪/深过户费按交易所路由，不叠加（对应 R1）。
- [ ] 过户费股数用 `raw_price`（对应 R2）。
- [ ] 压力情景仅改佣金率与滑点率；法定税费字段与基准情景逐字段相同（可用 diff 断言）。
- [ ] 经手费/证管费不出现在成本相加式（对应 R4）。
- [ ] 最低佣金 5 元/边在买入与卖出都生效；最低过户费 1 元/边仅在面额口径期间生效。
- [ ] 涨跌停 `P_ref` = 除权参考价；`ref_stale`、`limit_rule_mismatch`、`special_regime_unknown` 三条降级路径各有测试用例。
- [ ] `ST_UNKNOWN` 双口径开关默认 5%，可切换 10%，两口径结果分表。
- [ ] 容量三档参数化，默认 0.5%，并标 `ADV_APPROX`。
- [ ] 同日信号排序使用 `SHA256(seed | 候选周结束日 | 代码)`，seed=20261107。
