# EP-02 执行假设与不可精确还原项

- 版本：v0.3 候选配套文件（**未冻结**）
- 生成时间：2026-11-08
- 适用：ENTRY-PHASE-02 真实交易可行性验证
- 原则：**能从官方资料查到的必须查到；能从本地数据重建的必须重建；确实无法从日线恢复的，明确假设并采用保守处理。**

本文件只描述「当只有日线 OHLCV 时，如何把信号翻译成可执行成交」。它不定义信号，不定义策略，不包含任何回测结果。

## 0. 数据粒度事实（先于一切假设）

| 事实 | 影响 |
|---|---|
| `cache/stocks/*.parquet` 共 5,555 只，列为 `date, open, high, low, close, volume, amount` | 无逐笔、无委托队列、无盘口、无涨跌停封单量 |
| 价格为**不复权**原始价（数据源为新浪 `getKLineData`，未传复权参数） | 跨除权除息日存在价格跳空；涨跌停判定必须以除权参考价为基准 |
| `amount = volume × close` 为**近似成交额**（项目内已知近似，见 [stock_loader.py](../../data/stock_loader.py#L17-L19)） | 容量约束只能用近似 ADV，不能声称是真实成交额 |
| 复权数据仅 60 只（`cache/qfq/*.parquet`），复权因子仅 60 只（`cache/factors/*.json`） | 全池 5,555 只**没有**复权因子；EP-02 要么补建，要么显式按不复权处理 |
| 数据末日按缓存最后一根 bar（抽查为 2026-09-30，运行日 2026-11-07） | 「数据截止未平仓」的判定基准是各股最后一根 bar，不是运行日 |
| 停牌在数据中表现为**缺失 bar**，不是零成交行 | 只能以「bar 缺失」识别停牌，无法区分停牌原因 |

结论：**EP-02 中的所有成交都是日线代理成交，不是逐笔订单回放。**任何报告都必须带这句话。

## 1. 成交代理总则

1. **只在有效 bar 上成交**。某日无 bar（停牌/未上市/已退市）即不可成交，顺延。
2. **不使用当根 bar 之后的任何信息**。信号只能用 `w_end` 及之前的数据；成交只能用成交日当根 bar 的开/高/低/收。
3. **成交价一律为 bar 的开盘价**（入场与退出均如此），滑点另计。理由：开盘价是当日最早的可成交价，避免用收盘价制造「全天可自由成交」的假象。
4. **一天只做一次判定**：同一股票同一交易日不会既买入又卖出。

## 2. 入场（买入）代理

| 情形 | 判定 | 处理 |
|---|---|---|
| 正常交易日 | 开盘价不在涨停价 | 按开盘价 + 滑点买入 |
| 开盘价 = 涨停价 | 视为买不到 | 顺延至下一有效 bar |
| 一字涨停（`open=high=low=close=涨停价`） | 买不到 | 顺延 |
| 一字涨停但 `volume>0` | **仍按买不到处理**（保守） | 顺延；另统计该类占比作敏感性 |
| 开盘价 = 跌停价 | 可买入（卖方充足） | 按开盘价 + 滑点买入 |
| 无 bar（停牌） | 不可成交 | 顺延 |
| 顺延超过 10 个市场交易日 | 入场失败 | 记 `entry_fail`，该信号不进入收益统计 |
| 顺延期间数据结束 | 入场失败 | 记 `entry_fail_at_data_end` |

说明：`ENTRY_MAX_MKT_DAYS = 10` 是 EP-01 v1.2 已冻结的执行口径，EP-02 沿用，不新增放宽。

## 3. 退出（卖出）代理

1. **研究基准**：入场 bar 为第 1 个有效 bar，第 60 个有效 bar 的收盘价是研究口径的退出参考。
2. **真实执行**：从第 61 个有效 bar 起，按开盘价尝试卖出，遇到下列情形顺延：
   - 无 bar（停牌）；
   - 开盘价 = 跌停价（卖不掉）；
   - 一字跌停（`open=high=low=close=跌停价`），无论成交量多少，**一律视为卖不掉**（保守）。
3. **不设强制成交期限**。不允许「持满 10 天按跌停价成交」或「按最后收盘价成交」。必须等到真实可成交的第一个有效 bar。
4. **数据截止仍未成交**：记 `open_at_data_end`，按最后一根 bar 的收盘价估值计入期末净值，但**不认定为已实现退出**；报告中单列「期末未平仓」。
5. **卖出遇涨停**：可卖出（买方充足），按开盘价 − 滑点成交。
6. 退市/长期停牌导致永远无法卖出：记 `exit_impossible`，按最后可得收盘价估值，单列。

## 4. 涨跌停价计算

```
P_limit_up   = round_tick( P_ref × (1 + r) )
P_limit_down = round_tick( P_ref × (1 − r) )
```

- `P_ref`：**除权参考价**。无除权事件时 = 前一有效 bar 收盘价；有除权事件时 = 按分红送转/配股公式计算的除权参考价，**不得直接用前收盘价**。
- `r`：按 `HISTORICAL_MARKET_RULES.csv` 与 `HISTORICAL_SECURITY_STATUS.csv` 联合取值（板块 × 状态 × 日期）。
- `round_tick`：按最小价格变动单位 **0.01 元** 四舍五入。
- 若 `P_ref` 为缺失（前一日无 bar）→ 取最近一个有效 bar 的收盘价，但间隔 >5 个市场交易日时标记 `ref_stale`，该日不判涨跌停。
- 交叉校验：计算结果必须与当日 `high/low` 对照。若 `high > P_limit_up + tick` 或 `low < P_limit_down − tick`，标记 `limit_rule_mismatch`，该日按「不判涨跌停」处理并统计。
- **已知缺口**：主板 2014–2023 新股首日特殊安排、深市恢复上市/重新上市条款原文未取得（见 `HISTORICAL_SPECIAL_REGIMES.csv` 中 `未证实` 行），这些日期一律标 `special_regime_unknown`。

## 5. 封单与队列：明确不可还原

日线 OHLCV **不能**回答以下任何问题：

- 集合竞价时涨停价上排队多少手；
- 涨停是否「封死」（全天无成交 vs 有零星成交）；
- 我们的卖单在跌停打开瞬间能否排到队列前面；
- 盘中触及涨停后回落，我们的买单是否一定成交。

因此：

1. **不使用「封单量」作为任何判据**，也不试图从 `volume` 反推队列。
2. 采用本文第 2、3 节的**保守成交代理**：买不到就当买不到，卖不掉就当卖不掉。
3. 所有结论必须标注为「**近似成交模型（daily OHLC proxy）**」，不得表述为「真实可成交」。
4. 若未来接入 Level-2 逐笔或委托队列数据，本文件需整体重写，而不是打补丁。

## 6. 未知状态与特殊制度

| 情形 | 处理 |
|---|---|
| `status_unknown`（历史 ST 状态不可知） | 该日整笔记 `exec_unresolved`，不判涨跌停、不计入成功/失败分子分母；敏感性分析按 5% 更紧口径 |
| 科创板/创业板/主板注册制新股前 5 个交易日 | 不判涨跌停（无涨跌幅限制），允许成交 |
| 退市整理股票 | 首日无限制（按规则）；次日起主板 10%、创业板 20% |
| 恢复上市/重新上市首日 | 沪市不判涨跌停；深市原文未取得 → `special_regime_unknown` |
| 复牌首日 | 未找到额外特殊条款，按原板块比例；标 `resume_after_suspension` |
| 北交所 | 当前全 A 池不含北交所；若纳入需单独适用 30% 与首日规则 |
| 除权除息日 | 用除权参考价作 `P_ref`；收益计算必须使用复权收益或对除权跳空做调整 |

## 7. 容量约束

- 单笔买入金额上限 = **信号日之前 20 个有效交易日的日均成交额 × 0.5%**。
- 严禁使用买入日当天最终成交额（未来数据）。
- 由于 `amount` 是 `volume × close` 近似值，容量口径必须标注「近似 ADV」；若某股票 20 日窗口内有效 bar <15 根，该信号记 `adv_insufficient` 并降级为「不参与主判定」。
- 若按上限计算可买金额低于 5% 目标仓位，按可买上限买入，并记 `capacity_capped`。

## 8. 成本应用顺序（避免重复收费）

买入：

```
现金支出 = 成交金额 × (1 + 佣金率 + 滑点率) + 沪市过户费
沪市过户费 = 成交股数 × 面额(1元/股) × 过户费率   （2015-08-01 前为面额口径，之后为成交金额口径）
```

卖出：

```
现金收入 = 成交金额 × (1 − 佣金率 − 滑点率 − 印花税率) − 沪市过户费
```

硬约束：

1. **佣金为含规费口径**（含经手费、证管费），`HAND_*` 与 `REG_FEE` 只做交叉校验，**不得叠加**。
2. 深市 2015-08-01 前过户费为 0.0255‰ **从经手费中分成**，已含在佣金内，**不得另收**。
3. 印花税只在卖方、按成交金额；压力情景**不得**抬高法定税费，只调整佣金与滑点。
4. 单笔最低佣金 5 元/边必须计入。
5. 过户费最低 1 元/边仅适用于面额口径期间（2012-05-31 及之前）。

## 9. 失败率与未平仓（分开统计，不得合并）

| 指标 | 定义 | 分母 |
|---|---|---|
| 入场失败率 | `entry_fail` + `entry_fail_at_data_end` | 全部信号 |
| 退出延迟率 | 第 60 个有效 bar 后仍需顺延才卖出的笔数 | 已入场笔数 |
| 期末未平仓率 | `open_at_data_end` + `exit_impossible` | 已入场笔数 |
| 容量缩减率 | `capacity_capped` + `adv_insufficient` | 已入场笔数 |
| 状态不可判定率 | `exec_unresolved` | 全部信号 |

## 10. 不可精确还原清单（对结论的硬性限制）

| 项目 | 状态 | 替代方案 | 结论表述限制 |
|---|---|---|---|
| 涨跌停封单队列 | 不可还原 | 保守成交代理 | 只能称「近似可成交」 |
| 盘中触及涨跌停的瞬时成交 | 不可还原 | 按开盘价判定 | 不含日内择时能力 |
| 历史 ST/\*ST 状态区间 | 本地覆盖率 0% | 待建 PIT 表；未知即剔除 | 当前结论为「含未知口径」 |
| 真实成交额（用于容量） | 近似 | `volume × close` | 容量为近似口径 |
| 全池复权因子 | 仅 60 只 | 补建或按不复权处理 | 不复权时收益含除权跳空 |
| 主板 2014–2023 新股首日规则 | 未证实 | `special_regime_unknown` | 该段样本剔除 |
| 深市恢复/重新上市条款 | 未证实 | `special_regime_unknown` | 该段样本剔除 |
| 沪市过户费 1‰→0.5‰ 生效日 | 未证实 | 1‰ 为保守上界至 2012-05-31 | 成本略偏高，方向保守 |

## 11. 报告必须携带的声明

任何基于本文件产出的结果，必须原样附上：

> 本结果为日线级近似成交模型下的研究结论，不代表真实可成交收益。涨跌停封单队列不可还原，历史 ST 状态尚未重建，成交额为近似值。所有无法成交的笔次均按顺延或未平仓处理，未使用任何强制成交假设。
