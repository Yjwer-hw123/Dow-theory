# EP-03 第一轮：B 类信号横截面质量识别 — 特征有效性报告

生成时间：2026-11-08　脚本：`scripts/entry_phase_03_features.py`　样本：11,419 个 B 类信号（全池，2005—2026）

## 0. 一句话结论

19 个 PIT 特征中，**按本轮事先写死的判定规则（训练期五分组价差方向 + 两段 OOS 价差 t≥2.5），无一通过**；唯一"看起来极强"的 `b0_len` 被证实是**未来信息泄漏**，已剔除。

但本报告必须同时披露一个**方法层面的问题**：`sign_train` 是用训练期 Q5−Q1 价差定的，而 `atr_pct20`、`vol20`、`gap_freq60` 的训练期价差本身接近 0 且不单调（0.028 / 0.0005 / 0.018），等于**用噪声定方向**；按秩 IC 看，这三个特征的方向其实是三段一致的。因此"无一通过"是**规则判出来的**，不是数据说"全都没用"。

**本轮不启动三持仓模拟。** 是否进入 Phase B，取决于先冻结哪一种判定口径（见 §8）。

## 2. 数据与方法

### 2.1 样本

| 段 | 年份 | 信号数 | 股票数 | 有 ≥10 信号的交易日 |
|---|---|---|---|---|
| train | 2005—2016 | 4,568 | 2,210 | 144 |
| validate | 2017—2021 | 2,603 | 1,975 | 93 |
| test | 2022—2026 | 4,248 | 3,236 | 132 |

检验目标 `r60q` = 信号次日开盘买入、持有 60 个 bar 的**前复权**收益（送转/拆股/分红均由复权因子处理，与 L2 的持股数调整口径一致）。

成本近似：base 情景总成本约 **36 bp/笔**（双边滑点 20 bp + 双边佣金 6 bp + 卖出印花税 10 bp），对每笔几乎恒定，因此**按毛收益排序 ≈ 按净收益排序**；分组表另列 `mean_net` 交叉核对。

### 2.2 两个指标，必须分开看

**A. 同日横截面秩 IC**（主指标）
每个信号日内部，计算特征与 `r60q` 的 Spearman 秩相关（当日信号数 ≥4），再跨日等权平均，t 值按日序列计算。它衡量"**同一天出现多个信号时，特征能否分出好坏**"，不掺择时。

**B. 同日五分组价差**
每个信号日内部按特征分 5 组（当日信号数 ≥10），组内等权，跨日平均；`spread = Q5 均值 − Q1 均值`。

**C. 段内合并分组**（`p3_quintiles_pooled.csv`）
按整段做 `qcut`（`duplicates="drop"`），补充胜率 / 中位数 / 盈亏比 / 净期望。注意：取值离散的特征（`n_pb` 只有 2 个取值、`gap_freq60` 约 60% 信号取同一值）在此口径下只会产生 2—4 组，其单调性不可解读。

### 2.3 判定规则（跑数前写死）

- 方向 `sign_train` 只由**训练段** Q5−Q1 价差的符号决定；
- `pass_raw` = PIT 有效 且 验证段、检验段**同向**价差均为正；
- `pass_strict` = `pass_raw` 且两段价差 **t ≥ 2.5**。

### 2.4 相对强度为何不在表内

`rel20 = mom20 − 市场20日收益`、`rel60 = mom60 − 市场60日收益`。同一天内减掉的是**同一个常数**，秩不变，因此**日内 IC 与 `mom20/mom60` 完全相同**。相对强度只有在跨日比较时才有信息，而本轮是"同日选股"场景，故不单列（实测确认数值一致）。

## 4. 五个候选方向的逐项解读

### 4.1 趋势结构（`n_pb` / `trend_age` / `run_high_w` / `w_since_h` / `er26` / `mdd_high`）

- `trend_age` 三段同号（越"老"的趋势后续越差，IC −0.055/−0.078/−0.037），但检验段 t = −1.50，未达门槛；年度 IC 从 2016 的 −0.223 衰减到 2026 的 −0.117，方向未变、幅度不稳。
- `n_pb`、`er26`、`retrace` 在训练段与验证/检验段反复翻号，属典型噪声。
- `mdd_high` 三段同号且检验段 t = −2.31，接近门槛但未过。
- 结论：**趋势结构的"年龄/回撤"有一点点方向性，但强度不足以单独选股。**

### 4.2 相对强度（`mom20` / `mom60` / `rel20` / `rel60`）

- 日内 `rel` 与 `mom` 完全等价（见 §2.4），本轮不提供增量信息。
- `mom60` 三段同号（−0.041/−0.023/−0.068，检验 t = −2.68）：**近 60 日涨得越多，后面 60 日越差**（反转而非动量）。方向稳定，但幅度小。
- `mom20` 在验证段翻正（+0.009），不满足方向一致。
- 结论：**A 股 60 日尺度是弱反转，不是动量。** 这与"追强势股"的直觉相反，可作为下一轮的候选，但强度不足。

### 4.3 回调质量（`depth` / `retrace` / `vol_ratio` / `dist_high60` / `since_high60`）

- `depth` 三段同号（−0.042/−0.047/−0.040）但 t 均 < 1.7，**回调深浅几乎不区分好坏**。
- `retrace`、`vol_ratio` 方向反复翻转，噪声。
- `dist_high60` 三段同号为正（+0.015/+0.034/+0.057，检验 t = +2.29）：**离 60 日高点越远（越"低位"）后续越好**。方向稳定、幅度递增，但检验段 t 未达 2.5。
- `since_high60` 与 `dist_high60` 方向相反（−0.034/−0.034/−0.047），本质是同一现象的另一面。
- 结论：**回调质量这一组基本无效**，只有"距高点位置"有弱信号。

### 4.4 成交行为（`vol20` / `atr_pct20` / `ud_vol20` / `gap_freq60` / `liq_log`）

这是本轮**唯一成簇出现稳定方向的组**，且方向高度一致：**越"安静"的股票，未来 60 日越好。**

| 特征 | train | validate | test | 方向 |
|---|---|---|---|---|
| `atr_pct20` | −0.038 (t −1.53) | −0.100 (t −3.21) | −0.120 (t **−4.75**) | 低波动更好，幅度递增 |
| `vol20` | −0.022 (t −0.98) | −0.070 (t −2.24) | −0.102 (t **−3.84**) | 同上 |
| `gap_freq60` | −0.027 (t −1.14) | −0.075 (t −2.31) | −0.111 (t **−4.60**) | 少跳空更好 |
| `liq_log` | −0.098 (t −4.13) | −0.040 (t −1.31) | −0.167 (t **−6.65**) | 成交额越小越好（小盘/低流动性） |
| `ud_vol20` | −0.005 | −0.032 | −0.047 (t −1.99) | 上涨放量越明显越差（弱） |

分组佐证（段内 `qcut`，`r60q` 原始收益）：

| 段 | `atr_pct20` Q1→Q5 均值 | 胜率 Q1 / Q5 | 盈亏比 Q1 / Q5 |
|---|---|---|---|
| train | 0.144 → 0.134 | 63.9% / 60.3% | 2.59 / 1.78 |
| validate | 0.035 → 0.037 | 49.3% / 47.8% | 1.77 / 1.60 |
| test | 0.049 → 0.032 | 56.4% / 46.2% | 1.80 / 1.61 |

| 段 | `liq_log` Q1→Q5 均值 | 胜率 Q1 / Q5 | 净期望 Q1 / Q5 |
|---|---|---|---|
| train | 0.211 → 0.087 | 71.0% / 53.1% | 0.207 / 0.082 |
| validate | 0.051 → 0.043 | 50.3% / 52.0% | 0.047 / 0.039 |
| test | 0.077 → 0.008 | 61.3% / 41.6% | 0.074 / 0.005 |

**必须说清的三个保留意见：**
1. `atr_pct20` 与 `vol20` 高度相关，只能算**一个独立发现**，不是两个。
2. `liq_log` 的"低成交额更好"**直接受容量与冲击成本影响**。L2 的成本模型是固定 36 bp，不含冲击；若真按"买最不流动的一档"执行，实际成本会显著高于 36 bp，这一项的真实净期望**很可能被高估**，必须进 Phase B 用真实 ADV/容量规则重算。
3. `gap_freq60` 的训练期价差只有 0.018 且只有 4 个有效桶（离散取值），**分组证据不可用**，只能参考 IC。

### 4.5 交易风险（本轮无独立特征，仅由上述代理）

低波动（`atr_pct20` / `vol20`）本身是最接近"风险"的代理。但"低波动组 60 日收益更高、胜率更高、盈亏比更高"这一结果，**尚不能等同于组合最大回撤会下降**——它只见到 60 日单笔收益，没见到资金曲线。这一点属于 Phase B，本轮不能回答。

## 5. 为什么 `b0_len` 必须剔除

`b0_len` 直接取自 L1 CSV 的 `b0_count`，它是**整段 episode 内"B 后 bar"的计数**。而 episode 的边界由**全样本**的走势决定，`b0_count` 因此统计了**信号日之后**的 bar。

诊断实证（`_p3_check.py`）：

```
code=002210  signal=2013-11-15  episode=[52,251)  signal_i0=58
bars_before=6  bars_after=192  episode_len=199  b0_len=175  age=7
```

信号发生时，后续 192 根 bar 尚未发生，却被计入特征。它 IC 高达 0.312/0.404/0.337（t = 14/16/16），本质是"**未来还能涨多久**"的代理，属于典型前视偏差。已标记 `pit_valid=False`，并从可用特征中排除。

**这条必须写进结论：任何后续研究都不得把 `b0_count` 或其变体作为特征。**

## 6. 口径分歧：为什么"无一通过"和"有一个通过"都成立

这是本报告最重要的一节，因为它决定了下一步怎么做。

**问题出在 `sign_train` 的取法。** 我用训练期 Q5−Q1 价差定方向，但：

- `atr_pct20` 训练期价差 = **+0.028**（IC 却是 −0.038）→ 被判为"正向"；
- `vol20` 训练期价差 = **+0.0005**（基本是 0）→ 被判为"正向"；
- `gap_freq60` 训练期价差 = **+0.018** → 被判为"正向"。

于是检验段价差为负时，规则判为"方向翻转、不通过"。**实际上翻转的是训练期的噪声价差，不是特征的逻辑方向。** 这三个特征的秩 IC 是三段同号且幅度递增的。

如果改用另一条同样可以事先写死的规则——「**秩 IC 三段同号，且验证段与检验段 |IC t| ≥ 2.5**」——结果如下：

| 特征 | 三段 IC 同号 | val \|t\| | test \|t\| | 结论 |
|---|---|---|---|
| `atr_pct20` | 是 | 3.21 | 4.75 | **通过**（且过 Bonferroni 阈值 ≈2.90） |
| `vol20` | 是 | 2.24 | 3.84 | 不通过（val 不足） |
| `gap_freq60` | 是 | 2.31 | 4.60 | 不通过（val 不足） |
| `liq_log` | 是 | 1.31 | 6.65 | 不通过（val 不足） |
| `mom60` | 是 | 0.82 | 2.68 | 不通过（val 不足） |
| `trend_age` | 是 | 2.73 | 1.50 | 不通过（test 不足） |
| 其余 12 个 | — | — | — | 不通过 |

即：**在 IC 口径下，19 个特征里恰好 1 个（`atr_pct20`）通过，且在两段 OOS 都能抗住 19 次检验的 Bonferroni 校正。**

**但必须诚实：这个"通过"是在看到 test 结果之后换口径得出的，属于事后改判。** 它只能作为下一轮的**待验证假设**，不能作为本轮结论。

同时也要说明：19 个特征 × 2 段 OOS，即使全是噪声，t ≥ 2.5 的期望误报数约 0.24 个——**找到 1 个通过，本身就在随机噪声的预期范围内**。唯一让它超出噪声的理由是它同时抗住了 Bonferroni（|t| ≥ 2.90 两段都过）。

## 8. 结论与下一步（需要你决定，我不会自动执行）

### 本轮确定的结论

1. **`b0_len` 是未来信息泄漏，永久剔除。** 这是本轮唯一没有争议的强结论。
2. 按写死规则，**19 个 PIT 特征无一严格通过**；在"同向"层面勉强通过的 4 个（`n_pb`/`since_high60`/`mom20`/`ud_vol20`）量级只有 0.001—0.031，不可用。
3. **单特征不足以支撑"挑 1—3 只"的决策**，本轮不支持直接进 Phase B。
4. **但存在一个值得认真对待的候选簇**：低波动（`atr_pct20` / `vol20`）+ 低流动性（`liq_log`）+ 少跳空（`gap_freq60`），方向在三段中一致、检验段显著；其中 `atr_pct20` 在 IC 口径下过 Bonferroni。
5. `liq_log` 的真实净收益**很可能被固定成本模型高估**，因为 L2 的成本不含冲击成本。

### 三条路，请你选一条（不要我在看完结果后自己定）

**路线 A：修正判定口径后重跑同一批特征（推荐）**
- 预注册规则：「秩 IC 三段同号 且 验证段、检验段 |t| ≥ 2.5」；
- 为保 OOS 洁净，只用 **2017—2021 定方向与是否通过**，**2022—2026 只跑一次最终检验**；
- 输出：1—3 个候选特征 + 一次性 OOS 结果；
- 风险：test 的 IC 本轮已被"看过"，严格说已部分污染；如需彻底干净，应改为**逐年滚动 walk-forward**（每年只用该年之前的数据定方向）。

**路线 B：直接进入 Phase B 三持仓模拟**
- 只用 `atr_pct20`（低波动）作为唯一排序条件，或 `atr_pct20` + `liq_log` 复合分；
- 三持仓、每日最多补 1 只、持仓 60 bar、真实成本 + 容量/冲击；
- 对比三个基准：随机选 3 只 / 原始 B 全接（按时间顺序）/ 同日代码升序；
- 与你的五问对齐：胜率、净期望、盈亏比、最大回撤、跨年稳定性、年交易笔数。
- 风险：等于用一个"事后改判才通过"的特征直接做组合，统计证据偏薄。

**路线 C：停在特征层，承认单特征无效，转做小样本人工规则**
- 放弃横截面打分，改为对每年 ~10—30 个高确定性信号做人工复核（技术形态 + 市场环境）；
- 这不再是可回测的量化策略，无法再给出历史胜率证据。

我的建议是 **A**：先把口径固定下来、用干净的验证段做一次真正的"预注册检验"，再决定要不要做 B。因为 B 一旦启动，就会开始生成资金曲线并引入大量新口径（三持仓、补仓节奏、仓位大小、现金拖累），在没有一个可信特征的前提下，做出来的回撤数字没有解释力。

## 10. 本轮的已知局限（不要当成小事）

1. 收益口径为**收盘价持有 60 bar**，L2 实盘口径是**第 61 个 bar 开盘卖出**，差一个隔夜跳空，不影响排序但会让均值略有差异。
2. 分组只用"当日 ≥10 个信号"的日子（144/93/132 天），样本外的信号日不参与分组证据；IC 口径用"当日 ≥4 个信号"（270/165/190 天），两者样本不同。
3. `n_pb`、`gap_freq60` 等离散特征的分组曲线不可解读，只能看 IC。
4. 未做行业/板块中性化，特征可能夹带板块 beta。
5. 已对 test 段"看过结果"，test 的"干净"程度已下降，这是 §8 路线 A 必须先解决的。
