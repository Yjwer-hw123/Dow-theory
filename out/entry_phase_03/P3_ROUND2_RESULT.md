## 3. 逐年 walk-forward（不改变主结论，只提供稳定性证据）

每年方向只用该年之前的年度 IC（按信号数加权）确定，再看当年是否对齐。

| 特征 | 同号年占比 | 对齐后 IC 均值 | t | 说明 |
|---|---|---|---|---|
| `liq_log` | 0.810 (17/21) | +0.130 | **+4.00** | 2005—2026 长期最稳 |
| `trend_age` | 0.952 (20/21) | +0.096 | **+7.74** | 方向几乎年年成立，但幅度已衰减 |
| `mom60` | 0.667 | +0.063 | +2.68 | 弱反转，较稳 |
| `ud_vol20` | 0.762 | +0.056 | +4.07 | 较稳 |
| ⋯ | | | | |
| `atr_pct20` | **0.571 (12/21)** | **+0.010** | **+0.24** | **长期基本无效** |

**这是本轮最重要的发现：预注册规则选出的 `atr_pct20`，在 21 年 walk-forward 里的对齐后 IC 只有 0.010（t = 0.24），等于零。**

原因可直接看到：`atr_pct20` 的年度 IC 在 2017 年之前是**正负混杂**（2007 +0.181、2008 +0.153、2009 +0.304、2010 +0.216 为正；2011 −0.074、2012 −0.235、2014 −0.097、2015 −0.579 为负），2017 年以后才**稳定为负**。也就是说，它的"检验段显著性"建立在一次**因子换向（regime flip）**上，而不是贯穿历史的规律。

反过来，`liq_log`（低成交额小盘更优）和 `trend_age`（趋势越老越差）在 21 年里方向高度一致，却因为 2017—2021 这一段**恰好是它们的逆境期**而被冻结规则拒绝：

- `liq_log` 2017 +0.052、2019 +0.086、2020 +0.090 三年为正（对它不利），把 t 拖到 −1.31；
- 但它在 2005—2016 的 12 年里只有 2007（−0.036）一年接近零，其余全部显著为负，2015 单年 −0.516。

**结论：`atr_pct20` 通过的是"规则"，不是"规律"；`liq_log` 落选的是"窗口"，不是"效应"。**

## 4. 为什么我不建议直接拿 `atr_pct20` 进 Phase B

1. 它的长期稳定性在 18 个特征中靠后（同号 57%、t 0.24），检验段 −4.75 来自 2017 年后的单次换向。
2. 它与 `vol20`（选择段 t −2.24，差 0.26 落选）高度相关，本质是同一个"低波动"因子；而该因子在 2017 年前后方向相反，说明它更像**市场风格变量**，不是个股质量变量。
3. 若把这种"2017 年后才成立"的规则直接做成三持仓组合，回测区间（2022—2026）恰好整段落在它有效的风格期，**Phase B 会给出一个必然好看但不可外推的结果**——这正是 EP-02 里"盈利集中在 5 个年份"的同一类陷阱。

## 5. 下一道门（需要你决定，本轮不执行）

**选项 1：选择窗口敏感性检验（仍不碰 2022—2026）**
在 2005—2021 内滚动多个 5 年选择窗口（如 2008—2012、2010—2014、2012—2016、2017—2021），要求同一方向在**多数窗口**都过 `|t|≥2.5`，再对 2022—2026 做一次最终检验。
预期结果：`liq_log` / `trend_age` 会通过，`atr_pct20` 大概率不能全窗口通过。这一步能证明"上一轮选出的特征是窗口假象"。

**选项 2：把 `liq_log` 作为独立假设，先做容量与冲击成本专项**
"低成交额更优"在固定 36 bp 成本下成立，但真实执行会被冲击成本吃掉。先算：按 ADV 分档，5% NAV（5 万元）下单的冲击成本估计，以及各分档在 20 仓/3 仓下的可成交性。若扣掉冲击后 `liq_log` 的 IC 优势消失，则这条路自然关闭；若仍存在，它才配进 Phase B。

**选项 3：承认单特征在 60 日横截面上不足以选股，停止 EP-03**
回到 EP-02 的结论：B 类策略"能赚钱但风险不合格"，把精力放在仓位与退出规则，而不是选股。

我的建议顺序是 **选项 1 → 选项 2**：先用窗口敏感性把"是不是窗口假象"钉死，再对幸存者做成本现实性检验。两者都不产生资金曲线，风险最低；通过之后才谈三持仓模拟。
