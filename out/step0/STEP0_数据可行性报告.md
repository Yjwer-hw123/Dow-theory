## 3. 三周期支持与复权：结构通过，数据未通过

### 3.1 三周期结构

日线 OHLCV 对 5,555 只证券完整，沪深 A 交易日历可由 `000300` 指数日线（2002-01-04 起，6,000 个交易日）确定。月线/周线可以由日线聚合，不需要额外下载月/周行情：

- 月线：自然月内最后一个交易日收盘，形成已完成月 K；
- 周线：周一至周五内最后一个交易日收盘，形成已完成周 K；
- 未结束的月/周 K 必须丢弃，不能用于信号；
- 停牌 = 个股当日无 bar，不等于市场休市；PIT 池按“当日无 bar 即不在池”处理。

**结论：三周期结构可行。**

### 3.2 复权数据是硬阻断

`cache/stocks` 名义上是**不复权实际成交价**，但既含除权跳变，也含 `000001` / `000333` 的已知非正价格坏数据，不能视为可直接使用的干净 raw。

| 指标 | 数值 |
|---|---:|
| 含至少一次日收益 < -20% 的文件 | **4,346 / 5,555（78.2%）** |
| 日收益 < -20% 的总事件数 | **10,924** |
| 日收益 > +20% 的总事件数 | 5,059 |
| 非正收盘价文件 / 行数 | 2 / 3,927（000001 3,370 行；000333 557 行） |
| OHLC 逻辑违规文件 / 行数 | 6 / 9 |
| 含零成交量 bar 的文件 / 行数 | 34 / 43 |
| `amount == volume × close` 的文件 | 5,551 / 5,555 |
| `amount` 不等于该近似的文件 | 4 |

主板日跌停只有 -10%，创业板/科创板 -20%；出现 10,924 次 < -20% 的日收益，表明其中包含大量除权、送转、分红造成的价格跳变。**不复权数据不能用于月线 MA20、周线 MA60、未来收益、ATR 或回撤计算。**

现有前复权成果：

| 项目 | 数值 |
|---|---:|
| `cache/qfq/` 文件数 | **60 / 5,555（1.1%）** |
| 其中 HS300 / ZZ500 / wide | 3 / 9 / 12 |
| 其中退市股 | 13 |
| `qfq = raw / factor` 最大收盘误差 | 0.0 |
| `amount` 最大误差 | 0.0（成交额保持不变） |
| qfq 后日收益 < -20% | 13 / 342,256 个观测 |
| qfq 最后日期 | 2026-09-30 |

`scripts/build_qfq.py` 的路径是正确的：抓新浪前复权累计因子（每只约 1KB），用 `qfq = raw / f` 重建，退市股的因子端点在该脚本的 60 只冒烟测试中也有效。问题是**只做了 60 只，覆盖率 1.1%**。

**结论：三周期结构通过；复权口径未通过。进入 STEP 1 前必须为冻结后的股票池补齐 qfq。**

### 3.3 复权价、指标价、成交价的口径

必须固定为：

| 用途 | 价格口径 |
|---|---|
| 月线/周线/日线指标、收益、ATR | **前复权 qfq** |
| 实际成交（次日开盘买入、止损、退出） | **不复权 raw 开盘/最高/最低/收盘** |
| 量能过滤（C1 缩量、C2 1.5 倍量） | **raw volume**，不能用 qfq volume |
| 流动性/成交额排名 | **raw amount**（当前多为 `volume × close` 近似） |

原因：`build_qfq.py` 会把 `volume` 按复权因子放大，`amount` 保持不变。若用 qfq volume 做 5 日/20 日量比，会在除权日附近产生虚假的量能变化。

### 4.1 退市股的口径

| 指标 | 数值 |
|---|---:|
| 退市元数据 | 361 |
| 已缓存沪深 A | 333 |
| 最后 bar 与官方终止上市日完全一致 | 0 |

这不是数据错误：A 股退市前通常先停牌/整理，最后交易日早于“终止上市日”是常态。**PIT 和强制退出都应使用“最后可交易 bar”，不能用元数据里的终止上市日作为最后成交日。**

### 4.2 历史 ST 的具体缺口

- **深市**：`stock_info_sz_change_name('简称变更')` 提供 1994-2026 的简称变更事件，可以按“变更后简称含 ST/*ST”重建深市历史 ST 区间。
- **沪市**：`stock_info_change_name('600001')` 只返回无日期的曾用名（如 `G邯钢`、`邯郸钢铁`），无法直接重建 ST 起止日期；当前项目/akshare 封装内没有沪市批量历史 ST 数据。
- 因此**不能构建全市场逐日 ST 标记**。这会影响：ST 股是否从股票池剔除、ST 的 ±5% 涨跌停判断、退市风险处理。

### 4.3 板块归属与板块指数

申万历史分类文件覆盖全部 5,555 只缓存证券，且有多条“计入日期”记录，具备按 `计入日期 <= t` 取最新行业、做 PIT 归属的基础。但它只给行业代码，不给行业名称/指数代码；需要建立与 801xxx / 850xxx 指数的映射。现有申万 L1/L2/L3 指数历史接口可取，但尚未落盘。

探测备注：申万分类文件经本机代理下载成功（约 1.17MB），但默认证书链未通过校验，探测时使用了一次 `verify=False`。正式落盘前应配置可信 CA/代理，不能把该临时做法带进正式数据管道。

| 13 | **流动性排名的口径** | 成交额是近似值；全市场/板块内排名不同 | 20 日均成交额（raw `volume × close`），在当日合格池内做横截面百分位；第一版不做硬过滤，只在 STEP 3 消融。 |
| 14 | **初始止损、趋势退出与成交顺序** | ATR 口径、跳空、跌停、周线退出会改变单笔风险 | ATR(14) 用 **raw**；止损 = 入场价 - 2×ATR；次日跳空低于止损则按开盘成交；周线收盘跌破周 MA60 后下一交易日开盘退出；止损优先于趋势退出；不设固定止盈。 |
| 15 | **仓位、退市/停牌、T+1、涨跌停** | 不处理会造成“无法成交却计入收益” | 单笔风险 0.5% 净值；最多 5 只；不加仓；`size = 风险预算 / (entry - stop)`；无杠杆、现金上限；停牌不能卖、退市按最后可交易价强制退出；次日开盘一字涨停/停牌不买；T+1。 |
| 16 | **历史 ST 的处理方式** | 剔除/保留会直接改变样本和涨跌停规则；当前 ST 快照不能回填历史 | 若取得可信历史 ST，基线**剔除信号日 ST/*ST**；若拿不到，必须声明“未完整剔除历史 ST”，并做敏感性；**禁止用当前 ST 反推历史**。**阻断项** |
| 17 | **交易成本** | 成本口径不统一会让“净期望”失真 | 佣金/最低佣金/印花税/过户费/滑点必须来自券商合同或明确回测假设；`PA-action/config/account_cost.json` 目前全为 null，禁止用 0 占位。STEP 4 前补齐。 |
| 18 | **统计口径与多重检验** | 重叠窗口不能当独立样本；反复调参会产生假阳性 | 报告均值/中位数/正收益比例/样本 N，按年份和板块拆分；重叠 horizon 用日期块 bootstrap 给区间；参数网格预先固定，不为正收益反复改参数。 |
